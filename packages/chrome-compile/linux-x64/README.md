# Chromium 158 headless_shell — Linux x86_64

For EC2 launches, set `SSH_CIDR` to the public IPv4 range allowed to connect (normally your address with `/32`). `203.0.113.10/32` in the examples is a placeholder.

Builds Chromium **158.0.8127.2** `headless_shell` for generic Debian/Ubuntu
x86_64 (glibc ≥ 2.35), with proprietary codecs and PDF support.

## Overview

- **Target**: Ubuntu 22.04 / Debian 12 x86_64 (glibc ≥ 2.35)
- **Output**: `chromium-headless-shell-linux64.zip` containing
  `chrome-headless-shell-linux64/chrome-headless-shell` (NB: the binary is
  renamed from `headless_shell` to `chrome-headless-shell` at packaging time —
  Remotion's `BrowserFetcher` requires it; see top-level `README.md` →
  "Output zip layout requirements")
- **Build time**: ~1 h 20 min on `c6i.8xlarge` (32 Intel vCPUs)
- **Build environment**: `ubuntu:22.04` in Docker

## Chromium 157/158 notes

The build script handles:

- `args.gn` sets `angle_enable_gl = true` after the `headless.gn` import so
  `--gl=angle-egl` can use a native EGL driver (Chromium 158 build).
- The vpython store directory is `cpython-<hash>` with the depot_tools used by
  Chromium 158 (it was `cpython+<hash>`), so Step 5.5 locates Python 3.11 with
  `find` instead of a fixed glob.

- `enable_background_mode`, `enable_captive_portal_detection`,
  `enable_chrome_notifications`, `enable_platform_apps` and
  `enable_lens_desktop` are no longer forced off: `//chrome/test` and other
  full-graph targets now assert on them during `gn gen`.
- The build compiles the patched `page_handler.cc` objects right after
  `gn gen`, so a shared-memory patch error fails within minutes.
- Chromium's bundled Rust toolchain is used as-is (Step 12). Blink now needs
  headers generated by Crubit's `cc_bindings_from_rs`, which only accepts
  crates compiled by the rustc it ships with.
- `strip` skips zero-byte `libEGL.so` / `libGLESv2.so` placeholders.
- `setup-ec2.sh` keeps the container running and starts the build with
  `docker exec`, so a failed step can be fixed and resumed in place.

## Prerequisites

- **Instance**: `c6i.8xlarge` (32 x86_64 vCPU, 64 GiB RAM, Intel)
- **Storage**: 200 GiB gp3
- **AMI**: Amazon Linux 2023 host + Docker
- **Region**: eu-central-1

## Build

Follow the [Linux quick start](../README.md#quick-start), using this directory's files. The build script handles the toolchain setup and packaging; [args.gn](args.gn) and [the shared gclient configuration](../shared/.gclient) are the configuration sources.

## Output

`chromium-headless-shell-linux64.zip` contains `chrome-headless-shell-linux64/chrome-headless-shell` and its supporting files. The executable is renamed during packaging to match Remotion's [ZIP layout requirements](../README.md#output-zip-layout-requirements).

unzip chromium-headless-shell-linux64.zip
./chrome-headless-shell-linux64/chrome-headless-shell \
