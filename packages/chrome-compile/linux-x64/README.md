# Chromium 157 headless_shell — Linux x86_64

For EC2 launches, set `SSH_CIDR` to the public IPv4 range allowed to connect (normally your address with `/32`). `203.0.113.10/32` in the examples is a placeholder.

Builds Chromium **157.0.8080.0** `headless_shell` for generic Debian/Ubuntu
x86_64 (glibc ≥ 2.35), with proprietary codecs and PDF support.

## Overview

- **Target**: Ubuntu 22.04 / Debian 12 x86_64 (glibc ≥ 2.35)
- **Output**: `chromium-headless-shell-linux64.zip` (~92 MB), containing
  `chrome-headless-shell-linux64/chrome-headless-shell` (NB: the binary is
  renamed from `headless_shell` to `chrome-headless-shell` at packaging time —
  Remotion's `BrowserFetcher` requires it; see top-level `README.md` →
  "Output zip layout requirements")
- **Build time**: ~1 h 15 min on `c6i.8xlarge` (32 Intel vCPUs)
- **Build environment**: `ubuntu:22.04` in Docker

## Chromium 157 notes

Changes relative to the 149 recipe (details in the root `README.md`):

- `enable_background_mode`, `enable_captive_portal_detection`,
  `enable_chrome_notifications`, `enable_platform_apps` and
  `enable_lens_desktop` are no longer forced off: `//chrome/test` and other
  full-graph targets now assert on them during `gn gen`.
- The build compiles the patched `page_handler.cc` objects right after
  `gn gen`, so a shared-memory patch error fails within minutes.
- Chromium's bundled Rust toolchain is used as-is (Step 12). Blink now needs
  headers generated by Crubit's `cc_bindings_from_rs`, which only accepts
  crates compiled by the rustc it ships with, so the rustup nightly that 149
  substituted is gone.
- `strip` skips zero-byte `libEGL.so` / `libGLESv2.so` placeholders.
- `setup-ec2.sh` keeps the container running and starts the build with
  `docker exec`, so a failed step can be fixed and resumed in place.

## Why this is simpler than ARM64

| Aspect                  | ARM64                             | x86_64                    |
| ----------------------- | --------------------------------- | ------------------------- |
| LLVM toolchain          | Bootstrap from source (~13 min)   | Pre-built via `update.py` |
| Bootstrap targets patch | `ARM;AArch64` required            | Default `X86` is fine     |
| PIC patches             | Required for shared `libclang.so` | Not needed                |
| System `llvm-readelf`   | Required (multicall workaround)   | Not needed                |
| `compiler-rt` builtins  | Build separately                  | Included in pre-built     |
| `gperf` CIPD            | Missing on ARM64 → DEPS patch     | Works out of the box      |
| `mesa-common-dev`       | Required for `dri.pc`             | Pulled in by `libgl-dev`  |
| Wall time               | ~2 h 4 min                        | ~1 h 15 min               |

## Build steps

Single-phase. Rough script outline:

```
 1. Install depot_tools
 2. Clone Chromium (chromium.googlesource.com, shallow, 157.0.8080.0)
 3. Sync depot_tools
 5. gclient sync --no-history --shallow
 5.5 Symlink vpython's Python 3.11 → /usr/local/bin/python3
 6. Pre-built LLVM via tools/clang/scripts/update.py
 7. Node.js v24.12.0 (download x64 tarball directly)
 8. Java for build tools
 9. Build Ninja (after `ln -sf /usr/bin/python3 /usr/bin/python`)
10. Copy args.gn
11. Rust nightly derived from third_party/rust-toolchain/VERSION
12. cargo install bindgen-cli + symlink rustc/cargo/rustfmt/rustdoc/bindgen
13. Fix GCC paths (crtbeginS.o, crtendS.o)
14. depot_tools python3_bin_reldir.txt
15. gn gen + autoninja headless_shell
16. Strip and zip
```

See `build-chromium.sh` for the actual commands.

## Common build errors (what actually bit us on 149)

### `ImportError: cannot import name 'StrEnum' from 'enum'`

**Cause**: `autoninja.py` in 149 requires Python ≥ 3.11. Ubuntu 22.04 ships
3.10.
**Fix**: Step 5.5 — symlink vpython's bundled Python 3.11 over
`/usr/local/bin/python3` _and_ write the `depot_tools` `.cipd_bin` shim:

```bash
PY311=$(ls -d /root/.cache/vpython-root.0/store/cpython+*/contents/bin/python3.11 | head -1)
ln -sf "$PY311" /usr/local/bin/python3
ln -sf "$PY311" /usr/local/bin/python
mkdir -p /root/depot_tools/.cipd_bin
ln -sf "$PY311" /root/depot_tools/.cipd_bin/python3
echo ".cipd_bin" > /root/depot_tools/python3_bin_reldir.txt
```

### `gn gen` asserts on `enable_extensions=false` (and friends)

**Cause**: v149's `chrome/...` BUILD.gn files unconditionally reference
subsystems that these flags disable. `gn gen` now parses the full graph.
**Fix**: remove those flags from `args.gn`. Unused code is still not linked
into `headless_shell`.

### `update.py` fails to download clang

**Cause**: Network blocks `commondatastorage.googleapis.com`.
**Fix**: Retry; unblock the host; or build LLVM from source (but on x64 there's
no real reason to).

### `SKIA_USE_DAWN used without USE_DAWN`

**Fix**: `skia_use_dawn = false` in `args.gn`.

### Missing clang plugins (`find-bad-constructs`, `raw-ptr-plugin`)

**Fix**: `clang_use_chrome_plugins = false` in `args.gn`.

### `/usr/bin/env: 'python': No such file or directory` during Ninja build

**Fix**: `ln -sf /usr/bin/python3 /usr/bin/python` before Step 9.

### `unknown lang item: format_placeholder` / `-Z` flag rejected

**Cause**: Wrong Rust nightly for the bundled rustc.
**Fix**: derive the nightly date from `third_party/rust-toolchain/VERSION`
(Step 11). For 149.0.7790.0 this is `nightly-2026-02-28`. Install with
`--component rustfmt` and `--component rust-src`.

### `"third_party/rust-toolchain/bin/bindgen"` missing

**Fix**: `cargo install bindgen-cli` + symlink (Step 12).

### `"third_party/rust-toolchain/bin/rustfmt"` missing

**Fix**: `rustup toolchain install ... --component rustfmt`, then symlink it
into `third_party/rust-toolchain/bin/`.
