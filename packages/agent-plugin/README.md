# Remotion Codex Plugin

![Remotion](./assets/icon.png)

The official [Remotion](https://www.remotion.dev/) plugin for Codex. Create and
edit videos with React using skills for animation, audio, captions, charts,
maps, 3D scenes, transitions, and rendering. The plugin also helps you set up
projects, preview compositions in Remotion Studio, and export finished videos.

## Get started

[Install the Remotion plugin](https://chatgpt.com/plugins/plugins~Plugin_efd07789186881918253a50acfc32762?open_in_codex),
then describe the video you want to make. For example, ask for an animated bar
chart, a product announcement, or captions for an existing video.

See the [Codex plugin documentation](https://www.remotion.dev/docs/ai/codex-plugin)
for installation and usage instructions.

## Development

This repository is generated from
[`packages/agent-plugin`](https://github.com/remotion-dev/remotion/tree/main/packages/agent-plugin)
and [`packages/skills`](https://github.com/remotion-dev/remotion/tree/main/packages/skills)
in the Remotion monorepo. Changes made directly in this repository will be
overwritten by the release pipeline. Report issues and contribute changes in
[`remotion-dev/remotion`](https://github.com/remotion-dev/remotion).
