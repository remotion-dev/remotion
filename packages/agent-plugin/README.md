# Remotion Codex Plugin

![Remotion](./assets/icon.png)

The official [Remotion](https://www.remotion.dev/) Agent Plugin.

- **Make videos agentically**: Turn your idea into a video using your agent.
- **Make videos interactively**: Edit and animate like in a regular video editor.
- **Make videos programmatically**: Leverage web technology and own your video as code.

## Video Automation

- **Design systems**: Create a library of animated assets for your organization.
- **Batch rendering**: Render millions of videos on your own infrastructure.
- **Applications**: Publish a simple tool or a complex video editor.

## Get started

[Install the Remotion plugin](https://remotion.dev/plugins), then describe the video you want to make. For example:

```
/remotion-create See the videos in my downloads folder and put them on a timeline.
```

```
/remotion-create Make me a promo video for a record store
```

```
/remotion-create Please add captions to my video: ~/Downloads/IMG_0001.mov
```
