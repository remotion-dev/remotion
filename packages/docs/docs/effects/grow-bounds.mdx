# Grow bounds<AvailableFrom v="4.0.548" />

If you apply an [effect](/docs/effects) to an element, it might extend beyond the element's edges and overflow.

<video
  src="https://remotion.media/docs/effects/grow-bounds/clipped-wave-b23d35d773f3.mp4"
  width={1280}
  height={500}

/><br/><br/>

This is where the [`growBounds`](/docs/remotion/html-in-canvas#growbounds) prop on [`<HtmlInCanvas>`](/docs/remotion/html-in-canvas) comes in useful.  
It increases the canvas size, but keeps the position and the coordinate system of the canvas stable, so the content doesn't move.

## Programmatic example

Apply [`growBounds`](/docs/remotion/html-in-canvas#growbounds) to a [`<HtmlInCanvas>`](/docs/remotion/html-in-canvas) component:

```tsx twoslash title="WaveButton.tsx"
import {wave} from '@remotion/effects/wave';
import {HtmlInCanvas} from 'remotion';

export const WaveButton = () => (
  <HtmlInCanvas
    width={420}
    height={112}
    growBounds={86}
    effects={[wave({amplitude: 69, wavelength: 520, direction: 'horizontal'})]}
  >
    <button style={{width: '100%', height: '100%', borderRadius: 56}}>
      Continue →
    </button>
  </HtmlInCanvas>
);
```
