# tear()<AvailableFrom v="4.0.523" />

_Part of the [`@remotion/effects`](/docs/effects/api) package._

Rips through a canvas source along a jagged vertical edge, moving and rotating the torn pieces apart as the rip front advances.

## Example

```tsx twoslash title="MyComp.tsx"
import {tear} from '@remotion/effects/tear';
import {scale} from '@remotion/effects/scale';
import {Video} from '@remotion/media';
import {interpolate, staticFile, useCurrentFrame} from 'remotion';

export const MyComp: React.FC = () => {
  const frame = useCurrentFrame();
  const progress = interpolate(frame, [0, 30], [0, 1], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
  });

  return (
    <Video
      src={staticFile('video.mp4')}
      effects={[
        scale({scale: 1.12}),
        tear({
          progress,
          gap: 160,
          jaggedness: 80,
          frequency: 6,
          seed: 0,
          center: 0.5,
          rotation: 6,
          direction: 'top-to-bottom',
        }),
      ]}
    />
  );
};
```

Effects run in array order, so `scale()` preprocesses the source before `tear()`.

## API

Pass an object with the following properties. You can also call `tear()` without arguments.

### `progress?`

How far the rip has traveled through the source, from `0` to `1`. At `0`, the source is unchanged. As the value increases, the rip front advances in the selected `direction`. The cut stays narrow while traveling, then the pieces open during the final part of the animation. Defaults to `0.5`.

### `gap?`

Distance between the two pieces in pixels when `progress` is `1`. Defaults to `160`. Must be between `0` and `2000`.

### `jaggedness?`

Maximum horizontal variation of the torn edge in pixels. Use `0` for a straight split. Defaults to `80`. Must be between `0` and `1000`.

### `frequency?`

Number of large edge segments from top to bottom. Defaults to `6`. Must be between `1` and `100`.

### `seed?`

Changes the static shape of the torn edge. Defaults to `0`.

### `center?`

Horizontal position of the tear from `0` (left) to `1` (right). Defaults to `0.5`.

### `rotation?`

Outward rotation of each torn side in degrees. Positive values make the outer edges rotate downward; negative values rotate them upward. Defaults to `6`. Must be between `-45` and `45`.

### `direction?`

Direction in which the rip front travels. Use `"top-to-bottom"` or `"bottom-to-top"`. Defaults to `"top-to-bottom"`.

### `disabled?`

When `true`, the effect is skipped. Defaults to `false`.

## Requirements

`tear()` uses a WebGL2 backend. See [Using WebGL and WebGPU during renders](/docs/webgl).
