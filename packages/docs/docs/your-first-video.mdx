If this is your first experience with Remotion, you will have the easiest time by generating some content using [Agent Skills](/docs/ai/skills).

Make sure you have:

<Step>1</Step> [Set up a project](/docs). <br />
<Step>2</Step> Opened your project in a coding agent. Popular ones are [Codex](https://developers.openai.com/codex), [Claude](https://claude.com/product/claude-code), [Cursor](https://cursor.com), [Copilot](https://github.com/features/copilot), [OpenCode](https://opencode.ai) or
[Pi](https://pi.dev).

We like these initial prompts:

<SuggestedPrompt prompt="/remotion-create See the videos in my downloads folder and put them on a timeline." />

<SuggestedPrompt prompt="/remotion-create Make me a promo video for a record store" />
