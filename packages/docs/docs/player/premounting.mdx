# Premounting<AvailableFrom v="4.0.140" />

Premounting mounts a component before it appears, giving images, videos, and animations time to load and initialize.
It applies in the [Player](/docs/player/player) and [Studio](/docs/studio), and has no effect during rendering.

## What is premounting?

Without premounting, a component mounts when its time range begins. Its assets may still be loading when they should become visible:

<NoPremounting />

With premounting, the component mounts earlier, stays hidden, and waits at its first frame until its time range begins:

<Premounting />

## Premounting components

Pass [`premountFor`](/docs/img#premountfor) directly to the component you want to prepare. The value is the number of frames before its start at which it should mount.

- [`<Video>`](/docs/media/video) and [`<Audio>`](/docs/media/audio) from `@remotion/media`
- [`<Img>`](/docs/img), [`<AnimatedImage>`](/docs/animatedimage), [`<Gif>`](/docs/gif/gif)
- [`<Lottie>`](/docs/lottie/lottie), [`<RemotionRiveCanvas>`](/docs/rive/remotionrivecanvas)
- [`<AbsoluteFill>`](/docs/absolute-fill), [`Interactive` HTML and SVG components](/docs/interactive), [`<HtmlInCanvas>`](/docs/remotion/html-in-canvas), [`<Solid>`](/docs/solid)
- [`<Series>`](/docs/series), [`<Series.Sequence>`](/docs/series#premountfor), [`<TransitionSeries>`](/docs/transitions/transitionseries), [`<TransitionSeries.Sequence>`](/docs/transitions/transitionseries)
- [Shape components](/docs/shapes), [`<MacOSCursor>`](/docs/mac-cursors/mac-os-cursor), [rough-notation components](/docs/rough-notation/api)
- [`<ThreeCanvas>`](/docs/three-canvas), [`<ThreeWebGPUCanvas>`](/docs/three-webgpu-canvas)

Containers with a `layout` prop must use `layout="absolute-fill"` for premounting, including default premounting.

For example, this image mounts at frame 30 and becomes visible at frame 60:

```tsx twoslash title="PremountedImage.tsx"
import {Img, staticFile} from 'remotion';

export const PremountedImage: React.FC = () => {
  return (
    <Img
      from={60}
      premountFor={30}
      src={staticFile('logo.png')}
      width={200}
    />
  );
};
```

The same `from={60}` and `premountFor={30}` values work on a video, a Lottie animation, or any of the other components above. Each gets 30 frames to prepare before its start.

While premounted, components are hidden and do not respond to pointer events. Use `styleWhilePremounted` to customize these styles.

In the Studio timeline, diagonal stripes indicate the premounted range:

<img src="/img/premount.png" alt="A premounted range shown with diagonal stripes in the Studio timeline" />

Hide these indicators with [`Config.setShowPremounting(false)`](/docs/config#setshowpremounting) or the Studio settings. Premounting still runs, and child items may appear in the timeline while their parent is premounted.

## Premounting a whole scene

Set `premountFor` on a container such as [`<AbsoluteFill>`](/docs/absolute-fill) to prepare its children together:

```tsx twoslash title="PremountedScene.tsx"
import {AbsoluteFill, Img, staticFile} from 'remotion';

export const PremountedScene: React.FC = () => {
  return (
    <AbsoluteFill from={60} durationInFrames={90} premountFor={30}>
      <Img src={staticFile('logo.png')} width={200} />
      <h1>Welcome</h1>
    </AbsoluteFill>
  );
};
```

The image and heading mount at frame 30, become visible at frame 60, and unmount at frame 150.

A child can only premount while its parent is mounted. Premount the outer container when its children need to load before the scene starts.

For custom components, see [Make a component interactive](/docs/studio/make-component-interactive).

## Default premount duration<AvailableFrom v="4.0.535" />

Use [`defaultPremountInSeconds`](/docs/options/default-premount-in-seconds) to premount components without setting `premountFor` on each one. The default is `0` seconds in v4 and `2` seconds in [v5](/docs/5-0-migration), for both Studio and Player.

In the Studio, configure it with [`Config.setDefaultPremountInSeconds()`](/docs/config#setdefaultpremountinseconds), the [`--default-premount-in-seconds`](/docs/options/default-premount-in-seconds) CLI flag, or the Studio settings. The empty template already sets `2` seconds in its config file.

In the Player, pass the [`defaultPremountInSeconds`](/docs/player/player#defaultpremountinseconds) prop:

```tsx twoslash title="MyPlayer.tsx"
import {Player} from '@remotion/player';

const MyComposition: React.FC = () => null;
// ---cut---
export const MyPlayer: React.FC = () => {
  return (
    <Player
      component={MyComposition}
      durationInFrames={150}
      fps={30}
      compositionWidth={1920}
      compositionHeight={1080}
      defaultPremountInSeconds={2}
    />
  );
};
```

Seconds are converted to frames using the composition FPS and rounded to the nearest frame. At 30 FPS, `2` seconds means `60` frames of premounting.

An explicit `premountFor` overrides the default. Pass `premountFor={0}` to disable premounting for a component.

## Usage together with the buffer state

Loading an invisible component should not pause playback. Components that support the [buffer state](/docs/player/buffer-state), such as [`<Video>`](/docs/media/video), [`<Audio>`](/docs/media/audio), and [`<Img>`](/docs/img#pausewhenloading), do not trigger it while premounted. This also applies to [`<Html5Audio>`](/docs/html5-audio#pausewhenbuffering), [`<Html5Video>`](/docs/html5-video#pausewhenbuffering), and [`<OffthreadVideo>`](/docs/offthreadvideo#pausewhenbuffering) inside a premounted scene.

If an asset is still loading when it becomes visible, it can trigger the buffer state according to its buffering settings.
