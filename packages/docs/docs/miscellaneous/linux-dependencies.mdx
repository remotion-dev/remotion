If you are on Linux, Chrome Headless Shell requires some shared libraries to be installed.

## GLIBC requirements

Linux rendering requires glibc 2.35 or later. Amazon Linux 2023 on ARM64 is supported with glibc 2.34.

Amazon Linux 2023 on x64 is unsupported because it ships glibc 2.34. Use ARM64 or a distribution with glibc 2.35 or later, such as Ubuntu 22.04 or newer.

## Ubuntu 24.04

```bash
apt install -y \
  libnss3 \
  libdbus-1-3 \
  libatk1.0-0 \
  libasound2t64 \
  libxrandr2 \
  libxkbcommon-dev \
  libxfixes3 \
  libxcomposite1 \
  libxdamage1 \
  libgbm-dev \
  libcups2 \
  libcairo2 \
  libpango-1.0-0 \
  libatk-bridge2.0-0
```

## Amazon Linux 2023

Supported on ARM64 only. This is the exception to the glibc 2.35 requirement.

```bash
yum install -y \
  mesa-libgbm	\
  libX11 \
  libXrandr\
  libdrm \
  libXdamage \
  libXfixes \
  libxkbcommon \
  dbus-libs \
  libXcomposite \
  alsa-lib \
  nss \
  dbus \
  pango \
  cups-libs \
  at-spi2-core \
  atk \
  at-spi2-atk \
  libxkbcommon
```

## Alpine Linux

Not supported due to unsupported Libc symbols.

## nixOS

Not supported because Remotion ships with its own binaries of Chrome and FFmpeg that are not baked into the operating system.  
This conflicts with the "immutable distro" architecture of nixOS.
