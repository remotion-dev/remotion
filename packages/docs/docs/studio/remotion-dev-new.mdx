Under [remotion.dev/new](https://remotion.dev/new), we offer a Remotion [Studio](/docs/studio) that runs entirely in the browser.  
It runs a virtual file system and compiles React components using the [Rspack](https://rspack.rs) Browser API, so it is a full-featured Remotion project.

## What you can do

Under [remotion.dev/new](https://remotion.dev/new), you can:

- quickly scaffold a new Remotion project
- add [`<Solid>`](/docs/solid)'s, [effects](/docs/effects), images, videos, [canvas captures](/docs/canvas-capture), [elements](/docs/elements)
- change properties and set keyframes
- drag items around
- install packages
- [transcribe audio](/docs/whisper-webgpu) and separate [background from a video](/docs/video-matting)
- undo and redo
- download a project to your disk

## What you cannot do

The page is limited. Some major limitations are:

- You cannot edit the code of your project
- You cannot interact with an agent
- You cannot save a project

The best way to work with Remotion is locally using a real agent which has full access to your file system.  

remotion.dev/new is for exploring Remotion and quick prototyping. If you want to continue, we encourage you to download your project.
