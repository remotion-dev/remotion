## Add more libraries

### In Studio

Select Explore at the top of the Elements sidebar to discover libraries. Right-click empty space in the sidebar to add a library by URL.

Right-click an installed library to edit its name and URL, move it, or remove it. You can also drag libraries to reorder them.

### In `remotion.config.ts`

Add an Element Library with [`Config.addElementLibrary()`](/docs/config#addelementlibrary):

```ts twoslash title="remotion.config.ts"
import {Config} from '@remotion/cli/config';
// ---cut---
Config.addElementLibrary({
  url: 'https://example.com/elements',
  displayName: 'Acme Elements',
});
```
