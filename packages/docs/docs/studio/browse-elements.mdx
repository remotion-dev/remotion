[Remotion Elements](/elements) are available directly inside Remotion Studio.

## Open Browse Elements

In an editable Studio project, open Browse Elements from either:

- the welcome canvas when no composition is selected
- the **Actions** section in the right inspector when a composition is selected

<img src="/img/browse-elements-entry-points.png" alt="Browse Elements on the Studio welcome canvas and in the Actions section of the inspector" />

Choose an Element and click **Use**. Studio asks you to confirm before adding the Element's source code to your project.

## Add more libraries

Use the **Configure Elements** gear in the library window to manage Element Libraries. If additional libraries are configured, you can also choose **Manage…** from the Browse Elements menu.

Adding an Element Library makes its Elements available to browse. It does not install any Element into your project.

See the available [third-party Element Libraries](/elements/libraries).
