## Add more libraries

### In Studio

Use the **Configure Elements** gear in the library window to manage Element Libraries. If additional libraries are configured, you can also choose **Manage…** from the Browse Elements menu.

<img src="https://remotion.media/elements/studio/browse-elements-libraries.webp" alt="Element Libraries and Manage option in the Browse Elements menu" style={{maxWidth: '450px', width: '100%'}} />

### In `remotion.config.ts`

Add an Element Library with [`Config.addElementLibrary()`](/docs/config#addelementlibrary):

```ts twoslash title="remotion.config.ts"
import {Config} from '@remotion/cli/config';
// ---cut---
Config.addElementLibrary({
  url: 'https://example.com/elements',
  displayName: 'Acme Elements',
});
```
