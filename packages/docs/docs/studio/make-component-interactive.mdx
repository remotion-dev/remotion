# Make a component interactive<AvailableFrom v="4.0.530" />

Remotion's default components are already interactive, meaning they can be selected and edited in the Studio.

To make your component interactive too, wrap it with [`Interactive.withSchema()`](/docs/interactive-with-schema).

## Create the component

Create any component. Make sure it accepts `style` and passes it on to its visual root.
Styles for transforming, premounting, and cropping will be applied.

```tsx twoslash title="Badge.tsx"
import type React from 'react';

type BadgeProps = {
  readonly children?: React.ReactNode;
  readonly color?: string;
  readonly padding?: number;
  readonly style?: React.CSSProperties;
};

export const BadgeInner: React.FC<BadgeProps> = ({children, color = '#0b84ff', padding = 16, style}) => {
  return (
    <div
      style={{
        ...style,
        display: 'inline-flex',
        borderRadius: 999,
        backgroundColor: color,
        color: 'white',
        fontWeight: 700,
        padding,
      }}
    >
      {children}
    </div>
  );
};
```

## Create a schema

Define an [`InteractivitySchema`](/docs/interactivity-schema) to declare the props that may be interactively edited.

```tsx twoslash title="Badge.tsx"
import {Interactive, type InteractivitySchema} from 'remotion';

const badgeSchema = {
  color: {
    type: 'color',
    default: '#0b84ff',
    description: 'Color',
  },
  padding: {
    type: 'number',
    min: 0,
    step: 1,
    default: 16,
    description: 'Padding',
    hiddenFromList: false,
  },
  ...Interactive.transformSchema,
} as const satisfies InteractivitySchema;
```

[`Interactive.baseSchema`](/docs/interactive#interactivebaseschema) is added automatically - it includes things like `from`, `durationInFrames`, `trimBefore`, `freeze`, `playbackRate`, `name` and `showInTimeline`.

[`Interactive.premountSchema`](/docs/interactive#interactivepremountschema) is also added automatically, it allows for [premounting](/docs/player/premounting) components.

Include [`Interactive.transformSchema`](/docs/interactive#interactivetransformschema) to allow 2D and 3D transformations.

### Caption fields<AvailableFrom v="4.0.500" />

Include [`Interactive.captionsSchema`](/docs/interactive#interactivecaptionsschema) when the component accepts [`captions: Caption[]`](/docs/captions/caption) data:

```ts twoslash title="Captions.tsx"
import {Interactive, type InteractivitySchema} from 'remotion';

const captionsSchema = {
  ...Interactive.captionsSchema,
} as const satisfies InteractivitySchema;
```

Captions will become editable in the Studio.

## Turn on interactivity

Call `Interactive.withSchema()` to link the schema to the component.

```tsx twoslash title="Badge.tsx"
import type React from 'react';
import {Interactive, type InteractivitySchema} from 'remotion';

type BadgeProps = {
  readonly children?: React.ReactNode;
  readonly color?: string;
  readonly padding?: number;
  readonly style?: React.CSSProperties;
};

const BadgeInner: React.FC<BadgeProps> = ({children, color = '#0b84ff', padding = 16, style}) => {
  return (
    <div
      style={{
        ...style,
        display: 'inline-flex',
        borderRadius: 999,
        backgroundColor: color,
        color: 'white',
        fontWeight: 700,
        padding,
      }}
    >
      {children}
    </div>
  );
};

const badgeSchema = {
  color: {
    type: 'color',
    default: '#0b84ff',
    description: 'Color',
  },
  padding: {
    type: 'number',
    min: 0,
    step: 1,
    default: 16,
    description: 'Padding',
    hiddenFromList: false,
  },
  ...Interactive.transformSchema,
} as const satisfies InteractivitySchema;

export const Badge = Interactive.withSchema({
  Component: BadgeInner,
  componentName: '<Badge>',
  schema: badgeSchema,
  wrapInSequence: true,
});
```

## Enable cropping<AvailableFrom v="4.0.530" />

To make the component croppable, use `wrapInSequence: {cropping: true}`.

```tsx title="Badge.tsx"
export const Badge = Interactive.withSchema({
  Component: BadgeInner,
  componentName: '<Badge>',
  schema: badgeSchema,
  wrapInSequence: {cropping: true},
});
```

This adds [`Interactive.cropSchema`](/docs/interactive#interactivecropschema) and `crop*` props on the returned component.

```tsx title="MyComp.tsx"
<Badge cropLeft={0.2} cropBottom={0.1}>
  Sale
</Badge>
```

## Use the component

You can now use the component regularly.

In the Studio, it will render an outline and its props become editable.

```tsx title="MyComp.tsx"
import {AbsoluteFill} from 'remotion';
import {Badge} from './Badge';

export const MyComp = () => {
  return (
    <AbsoluteFill>
      <Badge from={30} durationInFrames={90} premountFor={30} color="#ff5c7a" style={{translate: '120px 80px'}}>
        Sale
      </Badge>
    </AbsoluteFill>
  );
};
```
