Press <kbd>⌘/Ctrl</kbd> + <kbd>K</kbd> to invoke the quick switcher. By default it will let you select a [composition](/docs/terminology/composition).  
In the input field, you filter for compositions by typing in their [ID](/docs/terminology/composition#composition-id).

## Searching assets

Type `$` as the first character to search files in your [public folder](/docs/terminology/public-folder).
Filter by file type with `type:audio`, `type:video`, `type:image`, `type:font`, `type:json`, `type:txt`, or `type:other`.
For example, `$ type:video intro` searches video filenames matching `intro`.

### LUT previews<AvailableFrom v="4.0.526" />

Use `$ type:lut` to find `.cube` color lookup tables.
Select a LUT in the Quick Switcher or the assets sidebar to compare a sample image before and after applying it.
Drag the divider across the image to compare the original and graded colors. You can also focus the slider and use the arrow keys, or press Home and End to reveal either version in full.
The sample image is loaded from `remotion.media` and requires an internet connection.

The preview supports standalone 1D and 3D LUTs, including custom input ranges.
Combined 1D/3D LUTs are not supported.
Previewing a LUT does not apply it to your compositions.

## Navigating through menu items

If you type "`>`" as the first character, you can navigate through the menu items.  
Add more characters after "`>`" to filter the menu items.

## Searching documentation

If you type "`?`" as the first character, you can search this very documentation.  
Add more characters after "`?`" to enter a query.

## Keyboard navigation

Use up and down arrow keys to navigate through the menu items.  
Press <kbd>Enter</kbd> to select the currently highlighted item and close the quick switcher.  
Press <kbd>Esc</kbd> to close the quick switcher.
