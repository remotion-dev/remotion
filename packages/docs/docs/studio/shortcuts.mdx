Open the Shortcuts tab in the Studio settings to see the shortcuts for the current project.

You can also press <kbd>?</kbd> to open this tab.

## Fixed shortcuts

Some shortcuts are context-sensitive interactions or browser events and cannot be overridden:

| Shortcut                                 | Action                                                               |
| ---------------------------------------- | -------------------------------------------------------------------- |
| `Left Arrow` / `Right Arrow`             | Move one frame or nudge the selected canvas item                     |
| `Shift+Left Arrow` / `Shift+Right Arrow` | Move one second or nudge the selected canvas item by a larger amount |
| `Shift`                                  | Select a range or lock the axis while dragging                       |
| `Cmd/Ctrl`                               | Toggle items in the selection                                        |
| `Cmd/Ctrl+V`                             | Paste effects or property values                                     |
| `Escape`                                 | Exit fullscreen                                                      |

## Keyboard navigation

Press <kbd>Tab</kbd> to navigate between controls and <kbd>Enter</kbd> to activate the focused control.

## Rendered-output previews<AvailableFrom v="4.0.540" />

Ready audio and video output previews, including local browser renders, support <kbd>Space</kbd>, <kbd>K</kbd> and <kbd>L</kbd> for playback; arrow keys, <kbd>A</kbd> and <kbd>E</kbd> for seeking; <kbd>&lt;</kbd> and <kbd>&gt;</kbd> for speed; <kbd>M</kbd> for mute; and <kbd>Shift+L</kbd> for looping. The corresponding customized shortcuts also apply.

<kbd>Shift</kbd> with an arrow seeks one second, and <kbd>Alt</kbd> with an arrow seeks to the beginning or end. While playing, <kbd>Enter</kbd> pauses and returns to where playback started. Rendered outputs do not support reverse playback with <kbd>J</kbd>.

These shortcuts yield to focused native media controls, editable fields and other controls, and to open dialogs. Native audio and video controls keep their browser keyboard behavior.

## Disabling keyboard shortcuts

Use [`Config.setKeyboardShortcutsEnabled(false)`](/docs/config#setkeyboardshortcutsenabled) or start the Studio with [`--disable-keyboard-shortcuts`](/docs/cli/studio#--disable-keyboard-shortcuts) to disable all shortcuts.

## Customizing shortcuts<AvailableFrom v="4.0.523" />

Select a shortcut in the settings and press a new key combination.

The Studio writes the override to `remotion.config.ts` using [`Config.setKeyboardShortcuts()`](/docs/config#setkeyboardshortcuts).

You can also edit the configuration file directly:

```ts twoslash title="remotion.config.ts"
import {Config} from '@remotion/cli/config';
// ---cut---
Config.setKeyboardShortcuts({
  playPause: {key: 'q'},
  toggleMute: {key: 'u'},
  toggleLoop: {key: 'y'},
  quickSwitcher: {key: 'p', commandOrControl: true},
  toggleSnapping: {key: 's', shift: true},
  selectVolumeProp: {key: 'v', shift: true},
  render: null,
});
```

Omitted actions keep their default shortcut. Set an action to `null` to disable it, or pass an array to assign multiple shortcuts.

`commandOrControl` uses Command on macOS and Control on other platforms. The `shift` and `alt` modifiers are also supported.

### Shared shortcuts

Some actions intentionally share a key: `selectRotateProp` and `render` use <kbd>R</kbd>, `selectOpacityProp` and `toggleCheckerboard` use <kbd>T</kbd>, and `selectEffects` and `jumpToEnd` use <kbd>E</kbd>. The selection action takes priority when it applies. Otherwise, the other action runs.

Each action can be remapped or disabled independently. For example, moving `selectEffects` to <kbd>Shift+E</kbd> leaves <kbd>E</kbd> available for `jumpToEnd`:

```ts twoslash title="remotion.config.ts"
import {Config} from '@remotion/cli/config';
// ---cut---
Config.setKeyboardShortcuts({
  selectEffects: {key: 'e', shift: true},
  jumpToEnd: {key: 'e', shift: false},
});
```

The Shortcuts settings allow these paired actions to share a custom key, while rejecting other conflicting assignments.
