# Motion blur

Motion blur shows where an object moved during a frame. [`@remotion/motion-blur`](/docs/motion-blur/index) offers three ways to make it, from a visible trail to a sampled exposure.

<Installation pkg="@remotion/motion-blur" />

| Component                                                                  | Appearance                                      | Preview                 |
| -------------------------------------------------------------------------- | ----------------------------------------------- | ----------------------- |
| [`<Trail>`](/docs/motion-blur/trail)                                       | Echoes of earlier positions                     | No special setup        |
| [`<CameraMotionBlur>`](/docs/motion-blur/camera-motion-blur)               | Blended layers across part of a frame           | No special setup        |
| [`<HtmlInCanvasMotionBlur>`](/docs/motion-blur/html-in-canvas-motion-blur) | Captured pixels averaged across part of a frame | Chrome 149+ with a flag |

Animate the content inside the component with [`useCurrentFrame()`](/docs/use-current-frame). The component samples that animation at different times within a frame. See the [common mistake](/docs/motion-blur/common-mistake) if the blur does not follow your animation.

## Trail

[`<Trail>`](/docs/motion-blur/trail) repeats earlier positions behind the current one. Choose it for a stylized echo or a long streak. It does not aim to reproduce a camera exposure.

<Demo type="motion-blur-trail" />

Set `layers`, `lagInFrames`, and `trailOpacity` to control the number, spacing, and visibility of the echoes.

## Camera motion blur

[`<CameraMotionBlur>`](/docs/motion-blur/camera-motion-blur) blends several copies of the content sampled at different times. It works in regular browsers, but layered blending can change colors and opacity. Use a low `samples` value and inspect the result.

<Demo type="motion-blur-camera" />

Set `shutterAngle` to control the exposure length and `samples` to control smoothness.

## HTML-in-canvas motion blur<AvailableFrom v="4.0.528" />

[`<HtmlInCanvasMotionBlur>`](/docs/motion-blur/html-in-canvas-motion-blur) captures the HTML at multiple fractional frames and averages the pixels in a canvas. This is the state of the art for motion blur in Remotion: it preserves the appearance of the sampled content better than stacking translucent DOM copies.

<Demo type="motion-blur-html-in-canvas" />

Live preview requires Chrome 149 or later with `chrome://flags/#canvas-draw-element` enabled. See the [HTML-in-canvas setup](/docs/html-in-canvas#enabling-the-flag-in-chrome). Other browsers show a rendered video of the demo. Remotion's bundled Chrome supports rendering without manual flag setup. [Nested HTML-in-canvas components](/docs/html-in-canvas#nested-html-in-canvas) are not supported yet.

Set `width` and `height` to the canvas size. Like the camera variant, `shutterAngle` controls exposure length and `samples` controls smoothness. See the [component reference](/docs/motion-blur/html-in-canvas-motion-blur) for defaults and ranges.
