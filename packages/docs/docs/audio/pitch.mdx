Use the `toneFrequency` prop to control the pitch of audio. During preview, it is supported by [`<Audio>`](/docs/media/audio) and [`<Video>`](/docs/media/video) from `@remotion/media`. During [server-side rendering](/docs/ssr), it is also supported by [`<Html5Audio>`](/docs/html5-audio), [`<Html5Video>`](/docs/html5-video), and [`<OffthreadVideo>`](/docs/offthreadvideo).

`toneFrequency` is not supported during [client-side rendering](/docs/client-side-rendering).

Values between `0.01` and `2` are accepted, where `1` represents the original pitch. Values less than `1` will decrease the pitch, while values greater than `1` will increase it.

A `toneFrequency` of 0.5 would lower the pitch by half, and a `toneFrequency` of `1.5` would increase the pitch by 50%.

The value can be changed while previewing, but it cannot be keyframed.

```tsx twoslash {7} title="MyComp.tsx"
import {Audio} from '@remotion/media';
import {AbsoluteFill, staticFile} from 'remotion';

export const MyComposition = () => {
  return (
    <AbsoluteFill>
      <div>Hello World!</div>
      <Audio src={staticFile('audio.mp3')} toneFrequency={0.8} />
    </AbsoluteFill>
  );
};
```
