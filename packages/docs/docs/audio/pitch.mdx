Use the [`toneFrequency`](/docs/media/audio#tonefrequency) prop to control the pitch of sound from both [`<Video>`](/docs/media/video) and [`<Audio>`](/docs/media/audio).

| Tag                                                        | Preview     | [Server-side rendering](/docs/ssr) | [Client-side rendering](/docs/client-side-rendering) |
| ---------------------------------------------------------- | ----------- | ---------------------------------- | ---------------------------------------------------- |
| [`<Audio>`](/docs/media/audio) from `@remotion/media`      | ✅ v4.0.520 | ✅ v4.0.357                        | ✅ v4.0.523                                          |
| [`<Video>`](/docs/media/video) from `@remotion/media`      | ✅ v4.0.520 | ✅ v4.0.357                        | ✅ v4.0.523                                          |
| [`<Html5Audio>`](/docs/html5-audio) from `remotion`        | ❌          | ✅ v4.0.47                         | ❌                                                   |
| [`<Html5Video>`](/docs/html5-video) from `remotion`        | ❌          | ✅ v4.0.47                         | ❌                                                   |
| [`<OffthreadVideo>`](/docs/offthreadvideo) from `remotion` | ❌          | ✅ v4.0.47                         | ❌                                                   |

Values between `0.01` and `2` are accepted, where `1` represents the original pitch. Values less than `1` will decrease the pitch, while values greater than `1` will increase it.

A `toneFrequency` of 0.5 would lower the pitch by half, and a `toneFrequency` of `1.5` would increase the pitch by 50%.

The value must stay constant for each audio or video asset. Animating or keyframing `toneFrequency` is not supported.

<Tabs groupId="media-type">
<TabItem value="video" label="Video">

```tsx twoslash title="MyComposition.tsx"
import {Video} from '@remotion/media';
import {staticFile} from 'remotion';

export const MyComposition = () => {
  return <Video src={staticFile('video.mp4')} toneFrequency={0.8} />;
};
```

</TabItem>
<TabItem value="audio" label="Audio">

```tsx twoslash title="MyComposition.tsx"
import {Audio} from '@remotion/media';
import {staticFile} from 'remotion';

export const MyComposition = () => {
  return <Audio src={staticFile('audio.mp3')} toneFrequency={0.8} />;
};
```

</TabItem>
</Tabs>

To change playback speed while keeping the original pitch, use [`preservePitch`](/docs/audio/speed#preserving-pitch) instead.
