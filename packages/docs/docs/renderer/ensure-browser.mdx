# ensureBrowser()<AvailableFrom v="4.0.137" />

Ensures a browser is locally installed so a Remotion render can be executed.

```tsx twoslash title="Simple usage"
import {ensureBrowser} from '@remotion/renderer';

await ensureBrowser();
```

```tsx twoslash title="Setting a specific Chrome version and listening to progress"
import {ensureBrowser} from '@remotion/renderer';

await ensureBrowser({
  onBrowserDownload: () => {
    return {
      version: '157.0.8080.0',
      onProgress: ({percent}) => {
        console.log(`${Math.round(percent * 100)}% downloaded`);
      },
    };
  },
});
```

## API

An object with the following properties, all of which are optional:

### `chromeMode?`<AvailableFrom v="4.0.248" />

<Options id="chrome-mode" />

### `browserExecutable?`

Pass a path to a browser executable that you want to use instead of downloading.  
If the path does not exist, this function will throw.  
Pass the same path to any other API that supports the `browserExecutable` option.

### `logLevel?`

<Options id="log" />

### `onBrowserDownload?`

Specify a specific version of Chrome that should be used and hook into the download progress.  
See the example below for the function signature.

We recommend returning `null` as the `version`. Remotion's default Chrome Headless Shell builds include optimizations such as [shared-memory capture](/docs/shared-memory-capture). Custom versions are stock builds from Google without them.

Remotion calls this function to determine which Chrome version to use, even if that version is already installed. It is not called if [`browserExecutable`](#browserexecutable) is passed.  
`onProgress` is only called if the returned `version` is not installed yet and needs to be downloaded. Log download messages in `onProgress` instead of in the function body.

From v4.0.544, each version is installed into its own folder. Installing a version does not delete other versions. If you use a custom version, pass the same `onBrowserDownload` function to every API that accepts it, such as [`renderMedia()`](/docs/renderer/render-media#onbrowserdownload) and [`selectComposition()`](/docs/renderer/select-composition#onbrowserdownload). Otherwise, those calls use Remotion's default version.

```tsx twoslash title="init.ts"
import {ensureBrowser, OnBrowserDownload, DownloadBrowserProgressFn} from '@remotion/renderer';

const onProgress: DownloadBrowserProgressFn = ({percent, downloadedBytes, totalSizeInBytes}) => {
  console.log(`${Math.round(percent * 100)}% downloaded`);
};

const onBrowserDownload: OnBrowserDownload = () => {
  return {
    // Pass `null` to use Remotion's recommendation.
    version: '157.0.8080.0',
    onProgress,
  };
};

await ensureBrowser({
  onBrowserDownload,
});
```

## Return value

A promise resolving to an object describing the browser that is now available. Its `type` field is `"user-defined-path"` if a [`browserExecutable`](#browserexecutable) was passed, otherwise `"local-puppeteer-browser"`. Both include the `path` of the executable.
