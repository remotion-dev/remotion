Remotion maintains a [plugin for GitHub Copilot](https://github.com/remotion-dev/agent-plugin).

It can help you create and edit Remotion projects and includes [Remotion Agent Skills](/docs/ai/skills).

## Installation

In [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/set-up/install-copilot-cli), install the plugin from the built-in Awesome Copilot marketplace:

```bash title="Terminal"
copilot plugin install remotion@awesome-copilot
```

See [GitHub's plugin installation documentation](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/plugins-finding-installing) for more details.
