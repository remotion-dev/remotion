# &lt;Track&gt;<AvailableFrom v="4.0.534" />

`<Track>` applies [`<Sequence>`](/docs/sequence) timing to its children and groups their clips on one Studio timeline row.
Enable [`Config.setExperimentalTracksEnabled(true)`](/docs/config#setexperimentaltracksenabled) to use the packed timeline presentation.

```tsx twoslash title="MyComposition.tsx"
import {Sequence, Track} from 'remotion';

export const MyComposition = () => (
  <Track name="Scenes" from={30} trimBefore={15} playbackRate={2} durationInFrames={90}>
    <Sequence durationInFrames={45}>
      <div>Intro</div>
    </Sequence>
    <Sequence from={45} durationInFrames={90}>
      <div>Main scene</div>
    </Sequence>
  </Track>
);
```

The track is visible on composition frames 30–74. Its children start at local frame 15 and advance twice as fast: the intro ends at composition frame 45, and the main scene is clipped at frame 75.

## Props

### `children?`

Content to group. Descendants that create timeline clips share the track row. Nested tracks create their own rows.

### `name?`

The track label. Defaults to `"Track"`.

### `from?`

The start frame in the parent timeline. Defaults to `0`. See [`<Sequence from>`](/docs/sequence#from).

### `durationInFrames?`

The number of child frames to display. Defaults to the remaining parent duration. See [`<Sequence durationInFrames>`](/docs/sequence#durationinframes).

### `hidden?`

Hide the track's content while keeping its timeline header. Defaults to `false`.

### `showInTimeline?`

Show the track and its children in the packed timeline. Defaults to `true`.

## Inherited props<AvailableFrom v="4.0.535" />

These props use the same behavior as [`<Sequence>`](/docs/sequence).

### `trimBefore?`

Advance the child clock without moving the track's start. Defaults to `0`. See [`trimBefore`](/docs/sequence#trimbefore).

### `playbackRate?`

Scale the child clock and the duration of its clips. Defaults to `1`. See [`playbackRate`](/docs/sequence#playbackrate).

### `loop?`

Repeat the selected child range until the parent ends. Defaults to `false` and requires a finite `durationInFrames`. See [`loop`](/docs/sequence#loop).

### `freeze?`

Hold the children at a local frame. Defaults to `null`. See [`freeze`](/docs/sequence#freeze).

### `width?`

Override the width returned by [`useVideoConfig()`](/docs/use-video-config) for children.

### `height?`

Override the height returned by [`useVideoConfig()`](/docs/use-video-config) for children.

### `controls?`

Pass controls from [`Interactive.withSchema()`](/docs/interactive-with-schema) when using a track inside a custom interactive component.

## Styling

`<Track>` does not create a container element and has no `layout` prop. Wrap its children in a `<div>` or [`<AbsoluteFill>`](/docs/absolute-fill) to apply styles or a class name.

Use [`<Sequence>`](/docs/sequence) for cropping, premounting, or postmounting. These container props are not supported on `<Track>`.

## Studio interactions<AvailableFrom v="4.0.535" />

Select the track header to edit From, Duration, Trim before, and Playback rate in the inspector.

Child clips can be moved and trimmed using their own timeline handles. The track's timing is edited in the inspector; splitting a track is unavailable.

Set `loop` and `freeze` in code. When either is active, the packed timeline displays one block for the track and hides its descendant rows. A repeated or frozen child does not have a single advancing interval that a packed clip could accurately represent.

`width` and `height` remain code-only.
