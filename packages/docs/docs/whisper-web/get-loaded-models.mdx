# ~~getLoadedModels()~~

:::info Deprecated
`@remotion/whisper-web` is deprecated and will no longer be published starting with Remotion 5.0. Use [`isWhisperModelCached()`](/docs/whisper-webgpu/is-whisper-model-cached) from [`@remotion/whisper-webgpu`](/docs/whisper-webgpu) instead. It checks one model and returns a boolean, so call it for each model you want to check.
:::

Returns an array of Whisper models that have already been downloaded and stored in the browser's IndexedDB storage.

```tsx twoslash title="app.ts"
import {getLoadedModels} from '@remotion/whisper-web';

const loadedModels = await getLoadedModels();
console.log(loadedModels); // ['tiny.en']
```

## Return value

Returns a Promise that resolves to an array of `WhisperWebModel` strings, representing the models that are already downloaded and available locally.
