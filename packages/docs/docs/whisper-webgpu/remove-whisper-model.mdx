# removeWhisperModel()<AvailableFrom v="4.0.523" />

Removes a Whisper model from memory and the persistent browser cache.

If the model is still loading or transcribing, removal waits for the operation to finish.

```ts twoslash title="remove-model.ts"
import {removeWhisperModel} from '@remotion/whisper-webgpu';

await removeWhisperModel({model: 'small.en'});
```

## Options

### model

One of the names returned by [`getAvailableModels()`](/docs/whisper-webgpu/get-available-models).
