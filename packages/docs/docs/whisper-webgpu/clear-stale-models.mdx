# clearStaleModels()<AvailableFrom v="4.0.518" />

Removes stale Whisper model files from the browser cache. Currently, these are the model files downloaded from Hugging Face by versions before 4.0.522. Current models downloaded from `remotion.media` and models used by other Transformers.js workflows are preserved.

Call this function when the page loads to free up storage used by outdated model files.

```ts twoslash title="clear-stale-models.ts"
import {clearStaleModels} from '@remotion/whisper-webgpu';

await clearStaleModels();
```

## Return value

A `Promise<void>` that resolves after stale models have been removed.
