# loadWhisperModel()<AvailableFrom v="4.0.518" />

Downloads a timestamped Whisper model from `remotion.media` and initializes it. Calling it before [`transcribe()`](/docs/whisper-webgpu/transcribe) lets you show model-loading progress.

```ts twoslash title="load-model.ts"
import {loadWhisperModel} from '@remotion/whisper-webgpu';

await using result = await loadWhisperModel({
  model: 'small.en',
  onProgress: ({progress}) => {
    console.log(progress);
  },
});

console.log(result.alreadyLoaded);
```

## Options

### model

One of the names returned by [`getAvailableModels()`](/docs/whisper-webgpu/get-available-models).

### onProgress?

Called while model files are resolved and downloaded. `progress` is the aggregate download progress between `0` and `1` and never decreases.

## Return value

### `alreadyLoaded`

Whether the same model pipeline was already loaded in memory.

### `[Symbol.asyncDispose]()`<AvailableFrom v="4.0.528" />

Releases this call's hold on the initialized model. The pipeline is disposed after every load handle is released and active transcriptions finish.

Use `await using` to call this method automatically when leaving the current scope. Call [`disposeWhisperModel()`](/docs/whisper-webgpu/dispose-whisper-model) to dispose the pipeline explicitly regardless of retained load handles.

[Transformers.js](https://huggingface.co/docs/transformers.js) manages the persistent model cache. Releasing the initialized pipeline does not delete the downloaded model files.

Versions before 4.0.522 downloaded models from Hugging Face. A model cached by an earlier version is downloaded once more from `remotion.media`, then reused from the new cache entry when using the default Transformers.js cache settings.
