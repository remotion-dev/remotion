# loadWhisperModel()<AvailableFrom v="4.0.518" />

Initializes a previously downloaded Whisper model on WebGPU. Call [`downloadWhisperModel()`](/docs/whisper-webgpu/download-whisper-model) first.

```ts twoslash title="load-model.ts"
import {downloadWhisperModel, loadWhisperModel} from '@remotion/whisper-webgpu';

await downloadWhisperModel({model: 'small.en'});
await using result = await loadWhisperModel({
  model: 'small.en',
});

console.log(result.alreadyLoaded);
```

## Options

### model

One of the names returned by [`getAvailableModels()`](/docs/whisper-webgpu/get-available-models).

### onProgress?

Called while the cached model is initialized. `progress` is `null` during initialization and `1` when ready. Use [`downloadWhisperModel()`](/docs/whisper-webgpu/download-whisper-model) for download progress.

### signal?<AvailableFrom v="4.0.528" />

An [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal) for canceling this call. Default: no cancellation signal. Initialization already in progress finishes before the promise rejects with the signal's reason. If no other call is using the model, it is disposed. Other callers loading or transcribing with the same model are unaffected.

## Return value

### `alreadyLoaded`

Whether the same model pipeline was already loaded in memory.

### `[Symbol.asyncDispose]()`<AvailableFrom v="4.0.528" />

Releases this call's hold on the initialized model. The pipeline is disposed after every load handle is released and active transcriptions finish.

Use `await using` to call this method automatically when leaving the current scope. Call [`disposeWhisperModel()`](/docs/whisper-webgpu/dispose-whisper-model) to dispose the pipeline explicitly regardless of retained load handles.

[Transformers.js](https://huggingface.co/docs/transformers.js) manages the persistent model cache. Releasing the initialized pipeline does not delete the downloaded model files.
