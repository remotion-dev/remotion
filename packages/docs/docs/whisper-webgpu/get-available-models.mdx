# getAvailableModels()<AvailableFrom v="4.0.518" />

Returns the timestamped Whisper models supported by [`transcribe()`](/docs/whisper-webgpu/transcribe).

```ts twoslash title="models.ts"
import {getAvailableModels} from '@remotion/whisper-webgpu';

const models = getAvailableModels();
console.log(models);
```

Each item contains the short `name`, Hugging Face `modelId`, parameter count, whether the model is multilingual, and estimated downloads for the default WebGPU and WASM configurations.

Available sizes are `tiny`, `base`, `small`, `medium`, and `large-v3-turbo`. English-only `.en` variants are available through `medium`.

The estimates cover model weights. Browser caches and supporting model files may add a small amount.
