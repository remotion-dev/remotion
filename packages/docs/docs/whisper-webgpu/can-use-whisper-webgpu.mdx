# canUseWhisperWebGpu()<AvailableFrom v="4.0.518" />

Asynchronously checks whether a usable WebGPU adapter is available in the current browser.

```ts twoslash title="support.ts"
import {canUseWhisperWebGpu} from '@remotion/whisper-webgpu';

const result = await canUseWhisperWebGpu();
if (!result.supported) {
  throw new Error(result.detailedReason);
}

console.log(result.supported);
```

An unsupported result includes a `reason` and `detailedReason`. WebGPU requires the WebGPU API, a usable adapter, and a secure context.

## Cross-origin isolation

Cross-origin isolation is not required.
