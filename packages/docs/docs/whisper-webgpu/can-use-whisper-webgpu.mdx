# canUseWhisperWebGpu()<AvailableFrom v="4.0.518" />

Asynchronously checks whether WebGPU transcription is supported in the current environment.

In a browser, WebGPU, a usable adapter, and a secure context (or localhost) are required. Node.js support is available from <AvailableFrom v="4.0.527" inline />. In Node.js, the function creates and disposes a tiny ONNX Runtime session using the WebGPU execution provider. This checks whether ONNX Runtime can acquire a WebGPU adapter without downloading a Whisper model or running inference.

```ts twoslash title="support.ts"
import {canUseWhisperWebGpu} from '@remotion/whisper-webgpu';

const result = await canUseWhisperWebGpu();
if (!result.supported) {
  throw new Error(result.detailedReason);
}

console.log(result.supported);
```

## Return type

A `Promise` resolving to a `CanUseWhisperWebGpuResult` object with the following properties:

### `supported`

_boolean_

`true` if WebGPU transcription is supported, `false` otherwise.

### `reason?`

If `supported` is `false`, a categorized reason why WebGPU transcription is not supported:

- `window-undefined`
- `webgpu-unavailable`
- `webgpu-requires-secure-context`

### `detailedReason?`

If `supported` is `false`, a human-readable explanation of why WebGPU transcription is not supported.
