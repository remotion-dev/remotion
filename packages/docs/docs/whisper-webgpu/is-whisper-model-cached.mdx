# isWhisperModelCached()<AvailableFrom v="4.0.518" />

Checks whether all files needed for a timestamped Whisper model from `remotion.media` are present in the persistent Transformers.js cache. The check does not download or initialize the model.

```ts twoslash title="model-cache.ts"
import {isWhisperModelCached} from '@remotion/whisper-webgpu';

const downloaded = await isWhisperModelCached({
  model: 'small.en',
});
```

## Options

### model

One of the names returned by [`getAvailableModels()`](/docs/whisper-webgpu/get-available-models).

## Return value

A `Promise<boolean>` resolving to `true` if every required model file is cached.

Models cached from Hugging Face by versions before 4.0.522 do not satisfy this check. Use [`downloadWhisperModel()`](/docs/whisper-webgpu/download-whisper-model) to download and cache a copy from `remotion.media`.
