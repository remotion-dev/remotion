# @remotion/whisper-webgpu<AvailableFrom v="4.0.518" />

Transcribe audio locally in the browser using timestamped Whisper models and WebGPU through [Transformers.js](https://huggingface.co/docs/transformers.js).

For new browser transcription integrations, prefer `@remotion/whisper-webgpu`. [`@remotion/whisper-web`](/docs/whisper-web) remains supported and is not deprecated, but requires cross-origin isolation and does not use WebGPU.

## Example

```ts twoslash title="transcribe.ts"
import {
  resampleTo16Khz,
  toCaptions,
  transcribe,
} from '@remotion/whisper-webgpu';

const file = new File([], 'audio.wav');
const channelWaveform = await resampleTo16Khz({file});

const transcription = await transcribe({
  channelWaveform,
  model: 'small.en',
  language: 'en',
});

const {captions} = toCaptions({whisperWebGpuOutput: transcription});
console.log(captions);
```

The model is downloaded on the first call and cached by the browser. Call [`loadWhisperModel()`](/docs/whisper-webgpu/load-whisper-model) first to display model download progress.

## Requirements

WebGPU requires HTTPS in production or `localhost` during development. Use [`canUseWhisperWebGpu()`](/docs/whisper-webgpu/can-use-whisper-webgpu) to check for a usable adapter.

Cross-origin isolation is not required.
