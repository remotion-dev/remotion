# Why create Elements

Elements are an open ecosystem. An [Element Library](/docs/elements/libraries) is your own website, and publishing one does not need our approval.

- A library builds your audience. It is published under your own name, and good Elements get used in other people's videos.
- Remotion Studio has more than 700,000 monthly active users. They can save your library in Studio, and add an Element with one click or by dragging it onto the canvas. AI agents and the CLI install from the same library.
- An Element is self-contained and [can expose its props and timing](/docs/elements/creating), so users restyle, trim and retime your work visually.
- [How you distribute Elements](/docs/elements/distributing) is your decision: free and open source, funded by sponsorships, or paid.
- We feature good libraries in the [official listing](/docs/elements/distributing#get-listed).
- We plan to make Elements installable in apps built with the [Remotion SDK](/docs/sdk), which is in development. Libraries would then also reach the users of those apps.
