# Why Elements?

[Elements](/docs/elements) are video building blocks whose source code is copied into your project.

## Why use Elements

### You own the code

An Element is not an npm package. Its source is copied into your project as a regular component, so you can restyle it, retime it or rewrite it, and no update can change it afterwards.

### Taste is the hard part

An AI agent can generate any animation from a prompt. Whether the result looks good is a different question: timing, easing, spacing and typography are judgment calls, and getting them right takes iterations.

An Element is the result of those iterations. Someone with an eye for motion design made the decisions, and the Element shares them. Sharing taste is what makes Elements valuable when code is cheap to generate.

Agents benefit too. An agent that adapts a well-made Element has a reference to match, instead of inventing a style on every prompt. The result is more predictable, and it looks the same in the next video.

### Elements compose

An Element is small and does one thing: a lower third, a marker stroke, a caption style. It is self-contained, so it works in any composition.

- Layer Elements as overlays on top of an existing video.
- Reuse the same Elements across projects to keep a consistent look.
- Collect them into a [design system](/docs/design-systems) for a brand or a team.
- Mix Elements from different libraries in one video.

### Editable without code

Elements can expose controls to the Inspector of Remotion Studio, so text, colors and timing can be changed visually. The code stays available for everything else.

To get started, see [Finding Elements](/docs/elements/finding) and [Using an Element](/docs/elements/using).

## Why create Elements

Elements are an open ecosystem. An [Element Library](/docs/elements/libraries) is your own website, with your own design and selection of Elements. Studio, the CLI and AI agents install from it by URL, and publishing one does not need our approval.

- A library builds your audience. It is published under your own name, on your own website, and good Elements get used in other people's videos.
- Your work is one click away from people making videos, because a library installs from Remotion Studio, the CLI and AI agents.
- **We plan to make Elements installable outside of Remotion Studio**, in apps that are built with Remotion. Libraries would then also reach the users of those apps.
- We point to libraries instead of collecting Elements in ours, and feature good ones in the [official listing](/docs/elements/distributing#get-listed).
- [How you distribute Elements](/docs/elements/distributing) is your decision: free and open source, funded by sponsorships, or paid.
- Animations that you made for your own videos can be published as they are. An Element is a component with a page and a payload.
