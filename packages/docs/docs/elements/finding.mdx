# Finding Elements

[Elements](/docs/elements) are published in Element Libraries. Each library is a website with its own selection.

## On the web

- [Element Libraries](/elements/libraries) lists the libraries that we feature.
- [Remotion Elements](/elements) is the library that we maintain.
- A library that is not listed works the same way. All that is needed is its URL.

Each Element has a page with a preview and its install actions.

## In Remotion Studio

Select **Browse Elements** in the **Actions** section of the right inspector. **Explore** at the top of the sidebar shows the same listing, and libraries of your project appear below it.

See [Browse Elements in Studio](/docs/studio/browse-elements).

## With an AI agent

With the [Remotion Agent Skills](/docs/agents/skills) installed, an agent can pick a fitting Element from a library that you name.

```text
/remotion-elements Find a lower third on https://www.remotion.dev/elements that fits my video.
```
