## Common props

Every component wraps the text or element passed as `children` and accepts these props:

### `children`

The text or element to annotate.

### `style?`

CSS styles applied to the tracked content. Text and font styles can also be edited in Remotion Studio.

### `progress`

Controls how much of the annotation is drawn. Use a value between `0` and `1`.

### `disabled?`

Set to `true` to temporarily hide the annotation while keeping the component and its other props in place. Default: `false`.

### `seed?`

Controls the generated shape. Change the integer on every frame to animate the shape. Default: `1`.

### `color?`

The annotation color. Default: `currentColor`.

### `roughness?`

Controls how rough the annotation looks. The default is `3` for `<Highlight>` and `1.5` for the other components.

### `maxRandomnessOffset?`

Controls how far points may be randomly offset from their ideal position. Default: `5`.

### `bowing?`

Controls how much straight lines bow. Default: `1`.

### `disableMultiStroke?`

Set to `true` to prevent Rough.js from drawing multiple strokes for a line. Default: `false`.

### `preserveVertices?`

Preserves vertices when roughening a shape. Default: `false`.

The components are interactive in Remotion Studio. They support editable text and font controls, as well as the following [`<Sequence>`](/docs/sequence) props: `durationInFrames`, `from`, `trimBefore`, `playbackRate`, `freeze`, `hidden`, `name` and `showInTimeline`.

### `premountFor?`<AvailableFrom v="4.0.528" />

Mounts the component before its `from` frame, keeping it transparent and frozen at its first frame so assets can load. The value is a number of frames. Defaults to `0` in v4 and `fps` (1 second) in v5. See [premounting](/docs/player/premounting).

### `postmountFor?`<AvailableFrom v="4.0.528" />

Keeps the component mounted after its duration ends, transparent and frozen at its last frame. Defaults to `0` frames. Requires a finite `durationInFrames`.

### `styleWhilePremounted?`<AvailableFrom v="4.0.528" />

CSS styles applied while premounted. Defaults to no overrides. These styles override `style` and the default `opacity: 0` and `pointerEvents: 'none'`.

### `styleWhilePostmounted?`<AvailableFrom v="4.0.528" />

CSS styles applied while postmounted. Defaults to no overrides. These styles override `style` and the default `opacity: 0` and `pointerEvents: 'none'`.

Premounting and postmounting apply in the [Player](/docs/player) and [Studio](/docs/studio), and are disabled during rendering. They do not add a wrapper element.
