This page tracks browser bugs and limitations affecting [HTML-in-canvas](/docs/html-in-canvas) that our community has reported.

## Browser reports

| Issue                                                                                                                      | Product | Filed by     | Status |
| -------------------------------------------------------------------------------------------------------------------------- | ------- | ------------ | ------ |
| [HTML-in-canvas does crash page on WebGL context loss](https://issues.chromium.org/issues/575053149)                       | Chrome  | @JonnyBurger | Open   |
| [A canvas with opacity: 0 can crash HTML-in-canvas](https://issues.chromium.org/issues/575053148)                          | Chrome  | @JonnyBurger | Open   |
| [HTML-in-canvas does not handle object-fit CSS property well](https://issues.chromium.org/issues/570832069)                | Chrome  | @JonnyBurger | Open   |
| [Nested HTML-in-canvas renders differently based on window.devicePixelRatio](https://issues.chromium.org/issues/540532973) | Chrome  | @JonnyBurger | Fixed  |
| [Relax restriction disallowing nested HTML-in-canvas](https://github.com/WICG/html-in-canvas/issues/120)                   | Chrome  | @JonnyBurger | Fixed  |

The scaling issue was also reported in [WICG/html-in-canvas#149](https://github.com/WICG/html-in-canvas/issues/149). Nesting support is tracked in [Chromium issue 527969910](https://issues.chromium.org/issues/527969910).

The WebGL context-loss crash was originally reported in [Remotion #12293](https://github.com/remotion-dev/remotion/issues/12293).
