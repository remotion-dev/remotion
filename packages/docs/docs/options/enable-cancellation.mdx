Allows a Lambda render to be cancelled by pressing Ctrl+C while running `npx remotion lambda render`. Enabling cancellation causes each renderer function to poll S3 once per second while it is running.

## CLI flag

Use `--enable-cancellation` with the following commands. Follow a command link for its syntax and examples.

| Command                                             | Flag                    |
| --------------------------------------------------- | ----------------------- |
| [`remotion lambda render`](/docs/lambda/cli/render) | `--enable-cancellation` |
