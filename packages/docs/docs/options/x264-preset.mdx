Sets a x264 preset profile. Only applies to videos rendered with `h264` codec.<br />Possible values: `superfast`, `veryfast`, `faster`, `fast`, `medium`, `slow`, `slower`, `veryslow`, `placebo`.<br />Default: `medium`
