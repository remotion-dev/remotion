The way timing works is standardized across these components:

- [`Interactive` elements](/docs/interactive), such as `<Interactive.Div>`, and [`<AbsoluteFill>`](/docs/absolute-fill).
- [`<Img>`](/docs/img), [`<CanvasImage>`](/docs/canvasimage), [`<AnimatedImage>`](/docs/animatedimage), [`<Solid>`](/docs/solid) and [`<HtmlInCanvas>`](/docs/remotion/html-in-canvas).
- [`<HtmlInCanvasMotionBlur>`](/docs/motion-blur/html-in-canvas-motion-blur) from `@remotion/motion-blur`.
- [`<Gif>`](/docs/gif/gif), [`<Lottie>`](/docs/lottie), [`<ThreeCanvas>`](/docs/three-canvas) and [`<RemotionRiveCanvas>`](/docs/rive/remotionrivecanvas).
- [`@remotion/shapes`](/docs/shapes), [`@remotion/rough-notation`](/docs/rough-notation/api), [`<MacOSCursor>`](/docs/mac-cursors/mac-os-cursor).
- [`<Audio>`](/docs/media/audio) and [`<Video>`](/docs/media/video) from `@remotion/media`.
- Custom components built with [`Interactive.withSchema()`](/docs/interactive-with-schema) that expose these props.

## `from`: Move an item

`from` moves an item on the timeline.  
By default, its children start at frame `0` when it appears:

<TimingTimeline from={30} trimBefore={0} playbackRate={1} loop={false} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div from={30}>
    <Counter />
  </Interactive.Div>
);
```

## `trimBefore`: Trim the beginning

`trimBefore` trims the beginning of an item.

<TimingTimeline from={30} trimBefore={15} playbackRate={1} loop={false} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div from={30} trimBefore={15}>
    <Counter />
  </Interactive.Div>
);
```

## `durationInFrames`: Set the duration

`durationInFrames` selects how many frames of the child timeline are shown, starting at `trimBefore`.
The item occupies `durationInFrames / playbackRate` frames in its parent timeline.

<TimingTimeline from={30} durationInFrames={60} trimBefore={45} playbackRate={2} loop={false} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div
    from={30}
    trimBefore={45}
    durationInFrames={60}
    playbackRate={2}
  >
    <Counter />
  </Interactive.Div>
);
```

## `playbackRate`: Change speed of an item

`playbackRate` changes the speed of its children.

<TimingTimeline from={30} durationInFrames={60} trimBefore={15} playbackRate={2} loop={false} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div
    from={30}
    trimBefore={15}
    durationInFrames={60}
    playbackRate={2}

    <Counter />
  </Interactive.Div>
);
```

## `loop`: Repeat an item

`loop` repeats the range selected by `trimBefore` and `durationInFrames` until the parent ends.

<TimingTimeline from={30} durationInFrames={60} trimBefore={45} playbackRate={2} loop />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div
    from={30}
    trimBefore={45}
    durationInFrames={60}
    playbackRate={2}
    loop
  >
    <Counter />
  </Interactive.Div>
);
```

To set a finite total duration for a loop, wrap it in an outer item with `durationInFrames`.
[`<Video>`](/docs/media/video) and [`<Audio>`](/docs/media/audio) may omit `durationInFrames` because they have an intrinsic duration.

## Order of operations

Think of the timing props as applying to the content in this order:

1. `from` positions the item in its parent timeline.
2. `trimBefore` sets the first frame in the child timeline.
3. `durationInFrames` selects the child range.
4. `playbackRate` stretches or compresses the selected range.
5. `loop` repeats the selected range until the parent ends.

## Formula

Child components calling [`useCurrentFrame()`](/docs/use-current-frame) get:

```md
trimBefore + (frame - from) * playbackRate
```

If the item loops:

```md
trimBefore + ((frame - from) * playbackRate) % durationInFrames
```
