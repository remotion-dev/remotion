The [`from`](/docs/sequence#from), [`durationInFrames`](/docs/sequence#durationinframes) and [`trimBefore`](/docs/sequence#trimbefore) props apply to these timeline components:

- [`Interactive` elements](/docs/interactive), such as `<Interactive.Div>`, and [`<AbsoluteFill>`](/docs/absolute-fill).
- [`<Img>`](/docs/img), [`<CanvasImage>`](/docs/canvasimage), [`<AnimatedImage>`](/docs/animatedimage), [`<Solid>`](/docs/solid) and [`<HtmlInCanvas>`](/docs/remotion/html-in-canvas).
- [`<Gif>`](/docs/gif/gif), [`<Lottie>`](/docs/lottie), [`<ThreeCanvas>`](/docs/three-canvas) and [`<RemotionRiveCanvas>`](/docs/rive/remotionrivecanvas).
- [`@remotion/shapes`](/docs/shapes), [`@remotion/rough-notation`](/docs/rough-notation/api), [`<MacOSCursor>`](/docs/mac-cursors/mac-os-cursor).
- [`<Audio>`](/docs/media/audio) and [`<Video>`](/docs/media/video) from `@remotion/media`.
- Custom components built with [`Interactive.withSchema()`](/docs/interactive-with-schema) that expose these props.

The listed components also accept `playbackRate`, except [`<Img>`](/docs/img) and [`<CanvasImage>`](/docs/canvasimage). Custom components must expose it in their schema.

## `from`: Move an item

`from` moves an item on its parent timeline. By default, its children start at frame `0` when it appears:

<TimingTimeline from={30} trimBefore={0} playbackRate={1} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div from={30}>
    <Counter />
  </Interactive.Div>
);
```

Drag the playhead across the element. At composition frame `30`, the counter on the left shows `30`, while the label inside the element and `<Counter>` show `0`. At composition frame `40`, the left counter shows `40` and the local frame is `10`.

## `durationInFrames`: Limit an item

`durationInFrames` sets how long an item stays on its parent timeline, starting at `from`. It does not change the frame seen by its children:

<TimingTimeline from={30} durationInFrames={45} trimBefore={0} playbackRate={1} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div from={30} durationInFrames={45}>
    <Counter />
  </Interactive.Div>
);
```

The item appears at composition frames `30` through `74`. The label inside the item and `<Counter>` run from `0` through `44`. Use `durationInFrames` to trim the end of `<Interactive.Div>`; it has no `trimAfter` prop.

## `trimBefore`: Trim the beginning

`trimBefore` skips the beginning of an item's content without moving it from its `from` position. For `<Interactive.Div>`, it advances the frame seen by its children when they first appear. It is available on `<Interactive.Div>` from <AvailableFrom v="4.0.482" inline />:

<TimingTimeline from={30} durationInFrames={45} trimBefore={15} playbackRate={1} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div
    from={30}
    trimBefore={15}
    durationInFrames={45}
  >
    <Counter />
  </Interactive.Div>
);
```

The element still occupies composition frames `30` through `74`. The counter on the left shows those frames, while the label inside the element and `<Counter>` run from `15` through `59`. On `<Audio>` and `<Video>`, the same `trimBefore={15}` starts playback 15 frames into the source while leaving the item at frame `30`.

## `playbackRate`: Change speed of an item

From <AvailableFrom v="4.0.528" inline />, `playbackRate` on `<Interactive.Div>` changes how quickly its children's frame advances. At `2×` speed, the child advances two frames for each composition frame:

<TimingTimeline from={30} durationInFrames={45} trimBefore={15} playbackRate={2} />

```tsx twoslash title="MyComposition.tsx"
import {Interactive, useCurrentFrame} from 'remotion';

const Counter = () => <div>{useCurrentFrame()}</div>;

export const MyComposition = () => (
  <Interactive.Div
    from={30}
    trimBefore={15}
    durationInFrames={45}
    playbackRate={2}
  >
    <Counter />
  </Interactive.Div>
);
```

At composition frame `30`, the label inside the element and `<Counter>` show `15`. At frame `40`, they show `35`. The element still lasts 45 frames on the parent timeline. Nested `<Interactive.Div>` elements apply their timing from the outer element to the inner one; their playback rates multiply. See [Order of operations](#order-of-operations) for how the timing props combine.

## Order of operations

For an item with children, the timing props apply in this order:

1. Use `from` and `durationInFrames` to determine whether the item appears on the parent timeline.
2. Subtract `from` from the parent frame.
3. Multiply by `playbackRate`.
4. Add `trimBefore`.

At parent frame `t`, [`useCurrentFrame()`](/docs/use-current-frame) inside the item returns:

```text
(t - from) * playbackRate + trimBefore
```

## Trim a media source with `trimAfter`

`<Audio>` and `<Video>` also accept `trimAfter` to select where playback stops in the source. Together with `trimBefore`, it selects a source range. `trimAfter` is the frame at which that range ends, not a number of frames to remove.

At 30 composition FPS, `trimBefore={45}` and `trimAfter={105}` select the source from 1.5 to 3.5 seconds. At double speed, it lasts 30 composition frames and appears from frame `30` through `59`:

```tsx twoslash title="MyComposition.tsx"
import {staticFile} from 'remotion';
import {Video} from '@remotion/media';

export const MyComposition = () => (
  <Video
    src={staticFile('video.mp4')}
    from={30}
    trimBefore={45}
    trimAfter={105}
    playbackRate={2}
  />
);
```

When `loop` is set, the selected source range repeats. Use `durationInFrames` to limit how long the loop remains on the composition timeline. Without a loop, `trimAfter` also limits how long the media can play.

The legacy [`<Html5Audio>`](/docs/html5-audio), [`<Html5Video>`](/docs/html5-video) and [`<OffthreadVideo>`](/docs/offthreadvideo) components also support source trimming. Wrap them in a `<Sequence>` to position them or limit their duration.
