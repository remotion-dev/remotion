# createElementPayload()<AvailableFrom v="4.0.502" />

Creates a validated, versioned Element payload for [`buildOpenInRemotionNewUrl()`](/docs/studio-protocol/build-open-in-remotion-new-url), [`setStudioDragData()`](/docs/studio-protocol/set-studio-drag-data), and [`installInStudio()`](/docs/studio-protocol/install-in-studio).

## Example

```ts twoslash title="element-payload.ts"
import {createElementPayload, staticFileRef} from '@remotion/studio-protocol';

const elementSourceCode = `
import {Img} from 'remotion';

export const MyElement = ({logoSrc}: {logoSrc: string}) => {
  return <Img name="Logo" src={logoSrc} />;
};
`;

const payload = createElementPayload({
  displayName: 'My Element',
  slug: 'my-element',
  sourceCode: elementSourceCode,
  dependencies: [
    {name: '@remotion/google-fonts', version: null},
    {name: 'color-namer', version: '1.4.0'},
  ],
  dimensions: {width: 900, height: 260},
  durationInFrames: 90,
  initialProps: {logoSrc: staticFileRef('my-element/logo.png')},
  assets: [
    {
      path: 'my-element/logo.png',
      type: 'url',
      url: 'https://example.com/logo.png',
    },
    {
      path: 'my-element/data.json',
      type: 'base64',
      data: 'eyJvayI6dHJ1ZX0=',
    },
  ],
});
```

## Arguments

Pass an object with the following properties.

### displayName

The name shown in the Studio confirmation dialog. It must be a non-empty string shorter than 120 characters.

### slug

A lowercase Element identifier. Its final path segment is used to create the `.element.tsx` filename. Directory traversal and unsafe filename characters are rejected.

### sourceCode

A string containing the complete Element source code. It must contain exactly one exported named component.

See [Integrating an Element Library with Studio](/docs/studio-protocol/component-library-integration) for recommended ways to preview a component and represent it as Element source in Vite-based projects and Next.js.

### dependencies

An array of npm packages needed by the Element. Declare each dependency as an object with `name` and `version` properties. Duplicate names are removed.

For `@remotion/*` packages, set `version` to `null`. Studio installs the version matching the Remotion project. Every non-Remotion package must specify an exact semantic version. Version ranges and tags are not accepted.

Do not declare `react`, `react-dom`, or `remotion`; every Remotion project already provides them.

### assets?<AvailableFrom v="4.0.528" />

Files to install in the project's public directory. The default is `[]`.

Set `path` to a forward-slash path relative to the public directory. Use [`staticFileRef()`](/docs/studio-protocol/static-file-ref) in `initialProps` to pass the installed asset to your component. Studio generates a [`staticFile()`](/docs/staticfile) expression on the component invocation and leaves the Element source unchanged. Paths cannot be absolute, contain traversal or platform-unsafe segments, or conflict with another declared asset path.

For a remote file, set `type` to `'url'` and provide an HTTP(S) `url` without credentials. For an embedded file, set `type` to `'base64'` and provide strictly encoded `data`. Browser Studio requires remote servers to allow cross-origin requests (CORS).

An installation can contain at most 100 assets and 50MB of downloaded or decoded data in total. The complete Element payload remains limited to 250,000 JSON characters, including embedded base64 data. Use remote URLs for larger files.

Studio fetches assets only after you confirm the installation. An existing file is reused when its bytes match. Different contents cause the installation to fail, even when you approve replacing an existing Element source file. Undo removes installed source changes but retains successfully installed assets; redo does not download them again.

Assets use Element payload version 2. Asset-free payloads continue to use version 1. A Studio that only supports version 1 asks you to upgrade instead of installing source without its assets.

### dimensions

The preferred width and height, or `null` for an Element without fixed dimensions. Both values must be positive finite numbers.

Studio uses these dimensions for the drag preview, drop position, composition registration, and the generated [`<Sequence>`](/docs/sequence). They are not passed to the component as `width` and `height` props. Legacy `'component-owned-sequence'` payloads also apply these dimensions to `style`.

### durationInFrames

The preferred duration shown while dragging. It must be a positive integer.

### initialProps?<AvailableFrom v="4.0.524" />

Props to write onto the installed component invocation and the standalone composition's `defaultProps`. The default is `null`. The component invocation is inside the generated [`<Sequence>`](/docs/sequence).

Use JSON-compatible values and valid JSX attribute names. Asset props can use [`staticFileRef()`](/docs/studio-protocol/static-file-ref), including inside nested objects and arrays. Studio turns these references into `staticFile()` expressions on the caller, not inside the Element source.

For legacy `component-owned-sequence` payloads, omit `from`, `durationInFrames`, and `name`; Studio supplies scene timing on the containing Sequence. In these payloads, `style` must be an object.

Pass the corresponding values to the component preview, using hosted URLs instead of asset references. Element dimensions are not passed as component props in `component-owned-sequence` mode, so include `width` and `height` when the component needs them.

### ~~installationMode?~~<AvailableFrom v="4.0.506" />

:::info Deprecated
Since <AvailableFrom v="4.0.536" inline />, Elements are registered as compositions on installation. Omit `installationMode` for new integrations.
:::

Both `'wrapped'` and `'component-owned-sequence'` remain accepted for existing libraries. Studio registers the copied component as a standalone composition and wraps its instances in a [`<Sequence>`](/docs/sequence) for timing, dimensions, and placement. The parent timeline item starts collapsed and can be expanded to inspect its children.

Legacy `'component-owned-sequence'` payloads preserve their initial style props and add the Element dimensions to `style`. The exported component and its Interactive schema are not rewritten. When omitted, the legacy value defaults to `'wrapped'`, or `'component-owned-sequence'` for caption styles.

Installing into a new composition creates only that composition, without an additional wrapper component file. Editing the copied Element source affects both its standalone composition and its instances. Other installed copies remain independent.

See [Design it for composition](/elements/guidelines#design-it-for-composition).

### isCaptionStyle?<AvailableFrom v="4.0.535" />

Set to `true` to let the Element be selected in the Styles tab when generating captions for a video or audio element. The default is `false`.

Caption styles must accept a `captions` prop containing [`Caption[]`](/docs/captions/caption) and expose it through [`Interactive.captionsSchema`](/docs/interactivity-schema#interactivecaptionsschema). When `installationMode` is omitted, [`createElementPayload()`](/docs/studio-protocol/create-element-payload) supplies the legacy caption-style value automatically. Use [`Interactive.withSchema()`](/docs/interactive-with-schema) with `wrapInSequence: true` to support `from`, `durationInFrames`, `trimBefore`, `playbackRate`, `premountFor`, and `postmountFor`.

Studio replaces preview captions with the generated transcript. Timing props in `initialProps` are ignored: Studio copies timing from the selected media so the captions stay in sync. To place the captions at the bottom center, Studio adds `bottom: 120`, `left: '50%'`, and `transform: 'translateX(-50%)'` to `style`; values from `initialProps.style` take precedence. Other initial props are preserved. Choosing a style does not install it; clicking Generate captions starts transcription, after which Studio installs its source, dependencies, and assets. The flag describes compatibility, not trust: an Element can execute arbitrary code.

## Return value

A `StudioElementPayload`. Asset-free payloads use version `1`; payloads with assets use version `2`. Pass the returned object unchanged to a transport API instead of serializing it manually.

Invalid input throws a `TypeError`.
