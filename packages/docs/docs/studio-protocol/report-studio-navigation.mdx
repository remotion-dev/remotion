# reportStudioNavigation()<AvailableFrom v="4.0.544" />

Updates the URL shown in Studio's Element Library header to the current page URL. Call it after the initial page load and whenever your router changes the URL, including query parameters and hashes.

Browsers prevent Studio from reading a cross-origin iframe's location. Your library must report navigation for the URL bar to stay up to date.

## Example

Call this from your router's navigation callback:

```ts twoslash title="navigation.ts"
import {reportStudioNavigation} from '@remotion/studio-protocol';

reportStudioNavigation();
```

For a React router, call it in an effect that runs when the current location changes. For full-page navigation, call it on every page after loading. Include back/forward navigation and hash changes.

## Behavior

Takes no arguments and returns nothing. Sends `window.location.href` to the parent frame. Studio accepts the URL only from its active library iframe and only when its origin matches the message sender.

Does nothing during server rendering, in a top-level window, or on origins other than HTTPS and localhost HTTP. Studio versions before v4.0.544 ignore the update.
