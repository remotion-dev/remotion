# @remotion/studio-protocol<AvailableFrom v="4.0.502" />

With this package, you can create payloads for passing content to Remotion Studio.

<Installation pkg="@remotion/studio-protocol" />

## Capabilities

### Installing Remotion Elements

Websites can provide [Elements](/elements) to a Studio either using drag-and-drop or using an installation dialog.

<Step>1</Step> Create an Element payload with [`createElementPayload()`](/docs/studio-protocol/create-element-payload).<br />
<Step>2</Step> Put it on a drag event with [`setStudioDragData()`](/docs/studio-protocol/set-studio-drag-data), or send a signal to a Studio using [`installInStudio()`](/docs/studio-protocol/install-in-studio).


| Method                                                                                              | Benefits                                                                                                        | Tradeoffs                                                                                                                                        |
| --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Drag-and-drop](/docs/studio-protocol/set-studio-drag-data)                                         | The user chooses the exact Studio tab, timeline position, and canvas position.                                  | Studio labels the source as [unverified](/docs/studio-protocol/security#confirmation-boundary). |
| [Installation dialog](/docs/studio-protocol/install-in-studio)                                     | The requesting website is shown.  Remotion attempts to bring the Studio to the foreground. | Always the most recently focused Studio is taken.                                         |

### Adding Element catalogs

Using [`addElementLibraryToStudio()`](/docs/studio-protocol/add-element-library-to-studio) you can request to add an element library to the Studio.

### Previewing Elements

Using [`buildOpenInRemotionNewUrl()`](/docs/studio-protocol/build-open-in-remotion-new-url), you can open your [Element](/docs/elements) in [remotion.dev/new](https://remotion.dev/new).
