# &lt;ChromeWordArt&gt;<AvailableFrom v="4.0.538" />

Slanted silver text with a reflective gradient and metallic outline.

```tsx twoslash title="MyComposition.tsx"
import {ChromeWordArt} from '@remotion/wordart';
import {AbsoluteFill} from 'remotion';

export const MyComposition = () => (
  <AbsoluteFill style={{justifyContent: 'center', alignItems: 'center'}}>
    <ChromeWordArt width={800} height={288}>
      Back to 1997
    </ChromeWordArt>
  </AbsoluteFill>
);
```

## Animation

The component has no automatic animation. Drive its props using [`useCurrentFrame()`](/docs/use-current-frame) and [`interpolate()`](/docs/interpolate).

```tsx twoslash title="AnimatedWordArt.tsx"
import {ChromeWordArt} from '@remotion/wordart';
import {interpolate, useCurrentFrame, useVideoConfig} from 'remotion';

export const AnimatedWordArt = () => {
  const frame = useCurrentFrame();
  const {fps} = useVideoConfig();
  const progress = interpolate(frame, [0, fps], [0, 1], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
  });

  return (
    <ChromeWordArt distortion={progress} depth={progress * 5}>
      WordArt
    </ChromeWordArt>
  );
};
```

## Props

Accepts the [common WordArt props](/docs/wordart#common-props), plus the following:

### depth?

Extrusion distance in SVG design units, from `0` to `40`. Default: `5`. Fractional values are supported.

### distortion?

Controls the slant, from `0` (straight) to `1` (full slant). Default: `1`.
