# &lt;WordArt&gt;<AvailableFrom v="4.0.537" />

Render a single line of decorative text using a [WordArt preset](/docs/wordart#presets).

```tsx twoslash title="MyComposition.tsx"
import {WordArt} from '@remotion/wordart';
import {AbsoluteFill} from 'remotion';

export const MyComposition = () => (
  <AbsoluteFill style={{justifyContent: 'center', alignItems: 'center'}}>
    <WordArt preset="rainbow" width={800} height={288}>
      Back to 1997
    </WordArt>
  </AbsoluteFill>
);
```

## Animation

The component has no automatic animation. Drive its props using [`useCurrentFrame()`](/docs/use-current-frame) and [`interpolate()`](/docs/interpolate).

```tsx twoslash title="AnimatedWordArt.tsx"
import {WordArt} from '@remotion/wordart';
import {interpolate, useCurrentFrame, useVideoConfig} from 'remotion';

export const AnimatedWordArt = () => {
  const frame = useCurrentFrame();
  const {fps} = useVideoConfig();
  const progress = interpolate(frame, [0, fps], [0, 1], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
  });

  return (
    <WordArt preset="orange" distortion={progress} depth={progress * 28}>
      WordArt
    </WordArt>
  );
};
```

## Props

### children

A string containing the text. Text is stretched horizontally to fit the preset, including short strings. It does not wrap. Use separate components for multiple lines.

### preset

One of `"rainbow"`, `"orange"`, `"blue-wave"`, or `"chrome"`. The type is exported as `WordArtPreset`.

### width?

The SVG width in pixels. Must be a finite number greater than zero. Default: `800`.

### height?

The SVG height in pixels. Must be a finite number greater than zero. Default: `288`. The artwork keeps its `1000:360` aspect ratio inside the given dimensions, including space for shadows and extrusion. Overflow is visible so font overhangs are not clipped. Set `style={{overflow: 'hidden'}}` to clip to the SVG bounds.

### fontFamily?

The font family for the letters. Default: `"Arial Black, Arial, sans-serif"`. [Load custom fonts](/docs/fonts) before rendering; this prop does not load fonts.

### fontWeight?

The font weight. Default: `900`. Choose a weight available in your loaded font.

### depth?

Extrusion distance in SVG design units, from `0` to `40`. The default depends on the preset: `0` for rainbow, `28` for orange, `12` for blue wave, and `5` for chrome. Fractional values are supported. The rainbow drop shadow is independent of extrusion.

### distortion?

Controls the preset's curvature or slant, from `0` (straight) to `1` (full effect). Default: `1`. A single character uses a straight baseline.

### style?

CSS styles applied to the root SVG. Use this for positioning, opacity, and transforms. Use `fontFamily` and `fontWeight` to change the letters.

### className?

A CSS class name applied to the root SVG.
