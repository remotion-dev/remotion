# Elements

An Element is a video building block written as a React component, such as an animated title, background, chart, or caption style.

<ElementsShowcase />

Creators publish Elements on websites called [Element Libraries](/elements/libraries). Adding an Element copies its source code into your project.

<ElementsFlow />

## Why Elements

### Taste is the hard part

An AI agent can generate any animation from a prompt. Whether the result looks good is a different question: timing, easing, spacing and typography are judgment calls, and getting them right takes iterations.

An Element is the result of those iterations. Someone with an eye for motion design made the decisions, and the Element shares them. Sharing taste is what makes Elements valuable when code is cheap to generate.

Agents benefit too. An agent that adapts a well-made Element has a reference to match, instead of inventing a style on every prompt. The result is more predictable, and it looks the same in the next video.

### You own the code

An Element is not an npm package. Its source is copied into your project as a regular component, so you can restyle it, retime it or rewrite it, and no update can change it afterwards.

### Elements compose

An Element is small and does one thing: a lower third, a marker stroke, a caption style. It is self-contained, so it works in any composition.

- Layer Elements as overlays on top of an existing video.
- Reuse the same Elements across projects to keep a consistent look.
- Collect them into a [design system](/docs/design-systems) for a brand or a team.
- Mix Elements from different libraries in one video.

In this video, the captions and the lower third are Elements layered over a recording. Toggle them to compare.

<ElementsComposeDemo />

### Editable without code

Elements can expose controls to the Inspector of Remotion Studio, so text, colors and timing can be changed visually. The code stays available for everything else.

### Open to any publisher

Any website can be an Element Library. Studio, the CLI and AI agents install from it by URL, and no approval from us is needed. See [Build Elements](#build-elements).

Run [`remotion elements use`](/docs/cli/elements/use) from your Remotion project with the URL of an Element's page. Replace the example URL with that URL and `MyVideo` with your composition ID.

```bash

```

The dry run (available in Remotion 4.0.543 and later) previews files, dependencies, and assets without changing your project. To install the Element, run the command again without `--dry-run`.

Install Elements only from websites you trust, since their source code runs in your project.

### Add an Element Library to Studio

Libraries that you add appear in [Browse Elements](/docs/studio/browse-elements) in Remotion Studio.

- On [Element Libraries](/elements/libraries), select Add to Studio on a library while Studio is running.
- In Studio, select Browse Elements, then right-click the sidebar and choose Add library… to enter a URL.
- From the command line, run [`npx remotion elements add-library`](/docs/cli/elements/add-library) with the library's URL.
- In `remotion.config.ts`, call [`Config.addElementLibrary()`](/docs/config#addelementlibrary).

```ts twoslash title="remotion.config.ts"
import {Config} from '@remotion/cli/config';
// ---cut---
Config.addElementLibrary({
  url: 'https://www.remotion.dev/elements',
  displayName: 'Remotion Elements',
});
```

You can rename, reorder, and remove libraries in Studio or in the config file.

## Build Elements

Elements are an open ecosystem. An Element Library is your own website, with your own design and selection of Elements, and publishing one does not need our approval.

### Why build Elements

- Your taste becomes reusable. Animations that you already made for your own videos can be published as Elements with a page and a payload.
- Your work is one click away from people making videos, because a library installs from Remotion Studio, the CLI and AI agents.
- A library carries your name. Good Elements get used in other people's videos, which builds a reputation and an audience.
- We point to libraries instead of collecting Elements in ours, and feature good ones in the [official listing](#get-listed).

<ElementLibraryStrip />

### Distributing Elements

How you distribute Elements is your decision, as with any app built with Remotion. Libraries can be free and open source, funded by sponsorships, or paid.

Most libraries are public. [Embedding the payload](/docs/elements/libraries#4-embed-the-payload) in each Element's page makes it installable for everyone, including agents.

To restrict access, for example for paid Elements, keep in mind that Studio receives only the [payload](/docs/studio-protocol/create-element-payload) that your website creates:

- Show the preview in a [`<Player>`](/docs/player) and the install actions to every visitor.
- When a user without access selects an install action, show the paywall or login instead of installing.
- Load the source code from your server after checking access, instead of bundling it into the page. Create the payload only then.
- Do not embed the payload in a public page. For CLI and agent installs, give each user a private URL that returns the JSON payload.

Installing an Element hands over its source code. State in your terms what users may do with it, such as using it in client work or redistributing it.

The license of an Element is separate from the [Remotion license](/docs/license), which applies to everyone who uses Remotion.

### Get started

<Step>1</Step> Clone the [Element Library template](https://github.com/remotion-dev/template-element-library), a working library website for previewing, installing and authoring Elements.<br />
<Step>2</Step> Build Elements with the [Element best practices](/docs/elements/creating), which cover design, portability, assets and Studio integration.<br />
<Step>3</Step> To add Studio support to an existing website instead, follow [Building Element Libraries](/docs/elements/libraries).<br />
<Step>4</Step> Deploy the website over HTTPS and share its URL. Anyone can add it to Studio.

### Get listed

We support libraries by featuring them on [Element Libraries](/elements/libraries), which is also the Explore view of Studio. The listing is curated: we look for original, well-crafted Elements.

To propose a library, contact [hi@remotion.dev](mailto:hi@remotion.dev). A library that is not listed still works everywhere by URL.
