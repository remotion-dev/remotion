# Using Elements

An Element is a reusable video building block written as a React component, such as an animated title, background, chart, or caption style.

## Find an Element

**[Browse the Elements catalog](/elements)**

Preview titles, backgrounds, charts, captions, and more in the catalog. You can also discover [third-party Element Libraries](/elements/libraries).

## In Remotion Studio

1. Open your composition in Remotion Studio.
2. Select **Browse Elements** in the **Actions** section of the right inspector.
3. Browse the library and choose an Element to add to your composition.

Studio copies the Element's source code into your project and installs its dependencies. Edit the copied code to customize it, or use its Inspector controls if it exposes them.

See [Browse Elements in Studio](/docs/studio/browse-elements) for a demonstration and instructions for adding more libraries.

## With the CLI

Use [`remotion elements use`](/docs/cli/elements/use) from your Remotion project with the URL of an Element's page. Replace the example URL with that URL and `MyVideo` with your composition ID.

```bash
npx remotion elements use https://example.com/elements/lower-third --composition MyVideo --dry-run
```

The dry run (available in Remotion 4.0.543 and later) previews files, dependencies, and assets without changing your project. To install the Element, run the command again without `--dry-run`.

The command asks for confirmation, copies the source, installs missing dependencies, and adds the Element to the composition at frame 0. Install Elements only from websites you trust, since their source code runs in your project.

See the [CLI reference](/docs/cli/elements/use) for supported URLs, version requirements, and flags.

## With an AI agent

[Install the Remotion Agent Skills](/docs/ai/skills), then use `/remotion-markup` when asking your agent to work on your video's content:

```text
/remotion-markup Add a lower third from the Elements catalog to my composition.
Use the Element's source code and adapt the text and colors to my video.
```

Give the agent the Element's page URL and your composition ID for a specific choice. Review the resulting code and preview it in Studio.
