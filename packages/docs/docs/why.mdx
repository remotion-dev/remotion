In a world with 1,000 video creation tools, why would you want to use Remotion?

## You want your video to be code

Code can express what a graphical user interface never could. Code can be encapsulated and reused. Code can scale. Code will connect to your data. Code has the best option for version control. Code is understood by your agents. Code can be automated.

## You want to use web technology

The web is the world's most popular graphics engine. Everybody has it installed. It gives you media, typography, layout, shaders, vectors and 3D, out of the box. It has gone through immense battle-testing and obsessive performance optimization. The web is open. Its ecosystem is massive.

## You want to compose your video

You want to encapsulate your elements and behaviors. You want to have 10 individually toggleable layers. You want to apply a shader to your HTML, then lay out and decorate it using CSS, then multiply it 5 times and add motion blur on top of all. You want to reuse and parameterize your elements.

## You want the best rendering options

You want to be able to render with the click of a button, from the command line, or programmatically using an API. You want to export videos, stills, GIFs, and image sequences. You want us to implement crazy optimizations for speed. You want to render on all operating systems, in Node.js, in any Docker container, in an Electron app. You want to render on AWS Lambda, Cloudflare, Azure Functions and on Vercel. You want to render directly in the browser. You want to potentially render millions of videos.

## You want to build an application

You want to embed a video player into your app. You want it to connect to your data. You want your player to be an interactive canvas. You want to start with a template. You want to build on a foundation used by over 2,000 [websites](https://www.wappalyzer.com/technologies/video-players/remotion/).

## You want to be empowered, not exploited

You don't want to be pushed towards a hosted platform. You don't want to log into an account. You don't want features to be paywalled. You don't want to be sold tokens or AI generations.

The way Remotion makes money is simple. It costs money for companies of four plus people. For everyone else, it is free. This works, and we don't have to make our product annoying.

## You don't want to reinvent

You want [building blocks](/elements), [templates](/templates), [transitions](/docs/transitions), and [effects](/docs/effects) to be there. You want to leverage our work of [thousands of iterations](https://github.com/remotion-dev/remotion/pulls?q=sort%3Aupdated-desc+is%3Apr+state%3Aclosed) from hundreds of contributors. You want to be in an open ecosystem where [third-party component libraries](/elements/libraries), [video editor templates](/docs/buy-a-video-editor), editing interfaces and [skills](https://github.com/Vincentwei1021/video-shotcraft) can exist.

## You want to be certain

Since 2021, we continuously improve Remotion almost every day. We are a sustainable, growing business. We don't have plans to change our business model or sell Remotion.
