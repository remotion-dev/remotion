# Canvas Capture

Canvas Capture is a high-fidelity screen recorder for micro-interactions.

It can record content at a higher resolution than the native display resolution.

Perfect for product demos showing closeups of UI.

:::warning

_Experimental_: Canvas Capture is not yet officially released. Features and behavior may change.

:::
