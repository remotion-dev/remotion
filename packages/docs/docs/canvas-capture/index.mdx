# Canvas Capture

Canvas Capture is a high-fidelity screen recorder for micro-interactions.

[![Comparison of a recompressed 1× screen recording and the same dropdown captured at 5× with Canvas Capture](https://remotion.media/canvas-capture/comparison-banner-2026-10-28-425780bb7e17.png)](https://remotion.media/canvas-capture/comparison-banner-2026-10-28-41685cc08bb5.mp4)

_A regular screen recording versus canvas capture._

It can record content at a higher resolution than the native display resolution.

Perfect for product demos showing closeups of UI.

:::warning

_Experimental_: Canvas Capture is not yet officially released. Features and behavior may change.

:::
