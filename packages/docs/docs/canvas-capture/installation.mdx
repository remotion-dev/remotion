# Install Canvas Capture

:::warning

_Experimental_: Canvas Capture is not yet officially released. Features and behavior may change.

:::

> Tip: Copy the URL of this page into an agent to let it install it for you.

Canvas Capture requires Chrome 157.0.8080.0 or newer with Canvas Draw Element enabled. Open `chrome://flags/#canvas-draw-element`, set Canvas Draw Element to Enabled, then restart Chrome.

## Install the extension

Install [Remotion Canvas Capture from the Chrome Web Store](https://chromewebstore.google.com/detail/remotion-canvas-capture/mfcdaccclejeibbmgoeokhbhgmcmlian).
