You can render any React/HTML markup in Remotion.  
You'll find it useful to use our pre-made components, which have timing primitives built in and show up in the Studio as layers and become interactive.

See the [API reference](/docs/api) for the full list of components, hooks and functions.

## HTML Elements

[`<Interactive.Div>`](/docs/interactive), `<Interactive.Span>`, `<Interactive.Svg>`, and so on work like regular HTML elements, but they make the layer show up in the Studio as a layer and interactive element.

## Video and audio

[`<Video>`](/docs/media/video) and [`<Audio>`](/docs/media/audio) can do the same as regular video tags in the browser - and more, such as pitch shifting and play more formats!

## Images and graphics

- [`<CanvasImage>`](/docs/canvasimage) and [`<Img>`](/docs/img) allow you to show images.
- [`<AnimatedImage>`](/docs/animatedimage) plays animate GIFs, PNGs, AVIFs or WebPs, but only in Chrome.
- [`<Gif>`](/docs/gif/gif) also plays GIFs, in all browsers.

## Grouping clips

- [`<Track>`](/docs/track) puts multiple clips on the row in the Studio timeline.
- [`<Series>`](/docs/series) plays multiple clips after each other. If you change the duration of one clip, others adjust.
- [`<TransitionSeries>`](/docs/transitions/transitionseries) is the same as `<Series>`, but allowing you to place transitions inbetween.

## Animation and 3D

- [`<Lottie>`](/docs/lottie/lottie) plays [Lottie](https://lottie.airbnb.tech/#/) animations, useful for displaying content from After Effects.
- [`<RemotionRiveCanvas>`](/docs/rive/remotionrivecanvas) plays [Rive](https://rive.app/) content.
- [`<ThreeCanvas>`](/docs/three-canvas) enables you to render Three.js content.

## Shapes and annotations

- [`@remotion/shapes`](/docs/shapes) has SVG shapes such as [`<Heart>`](/docs/shapes/heart), [`<Arrow>`](/docs/shapes/arrow) and [`<Star>`](/docs/shapes/star).
- [`@remotion/rough-notation`](/docs/rough-notation/api) allows for animated, hand-drawn annotations such as highlights on text.
- [`<MacOSCursor>`](/docs/mac-cursors/mac-os-cursor) displays a macOS cursor that you can position and animate, for example in a product demo.

## Effects

- [`<Solid>`](/docs/solid) is a simple, generic component, useful for applying [effects](/docs/effects).
- [`<HtmlInCanvas>`](/docs/remotion/html-in-canvas) wraps any content and allows you to add an effect to it.
- [`<HtmlInCanvasMotionBlur>`](/docs/motion-blur/html-in-canvas-motion-blur) adds motion blur to its children.

## Make your own

Use [`Interactive.create()`](/docs/interactive-create) to make your own React components editable in the Studio and inherit timing primitives.
