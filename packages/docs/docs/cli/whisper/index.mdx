# npx remotion whisper<AvailableFrom v="4.0.546" />

Transcribe local media with [`@remotion/whisper-webgpu`](/docs/whisper-webgpu/) and download, list, and remove Whisper models.  
This command uses the Transformers.js filesystem cache, and it is shared with the Node.js package.
