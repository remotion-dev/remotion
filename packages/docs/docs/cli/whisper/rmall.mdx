# npx remotion whisper rmall<AvailableFrom v="4.0.546" />

Remove all Whisper models from the local cache, including partially downloaded models.  
The cache is shared with [`@remotion/whisper-webgpu`](/docs/whisper-webgpu).  
The command asks for confirmation in an interactive terminal.

```bash title="Clear the local Whisper model cache"
bunx remotion whisper rmall
```

## Flags

### `--yes`, `-y`

Skip confirmation. Pass this flag to clear the cache in scripts or CI.
