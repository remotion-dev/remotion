# npx remotion whisper install<AvailableFrom v="4.0.546" />

Download a named model to the local cache. Use [`whisper ls`](/docs/cli/whisper/ls) for model names and download sizes.

```bash title="Download the tiny English model"
bunx remotion whisper install tiny.en
```

Progress shows the amount downloaded and the estimated total model size. An existing cached model is reused. [`whisper transcribe`](/docs/cli/whisper/transcribe) also downloads its model automatically when needed.
