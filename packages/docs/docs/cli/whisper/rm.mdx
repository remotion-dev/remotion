# npx remotion whisper rm<AvailableFrom v="4.0.546" />

Remove a Whisper model from the local cache.  
The cache is shared with [`@remotion/whisper-webgpu`](/docs/whisper-webgpu).

```bash title="Remove the tiny English model"
bunx remotion whisper rm tiny.en
```

Use [`whisper rmall`](/docs/cli/whisper/rmall) to clear all cached Whisper models.
