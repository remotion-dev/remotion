Scaffold a new Remotion project.

```bash
npx create-video --yes --blank my-video
```

If no arguments are passed, an interactive TUI will guide you through the setup.

## Arguments

### `<directory>`

The directory in which the project should be created.

The recommended starter command creates a blank project in the `my-video` directory:

```bash
npx create-video --yes --blank my-video
```

## Flags

### `--yes`<AvailableFrom v="4.0.439" />

Enable non-interactive mode. All prompts are skipped with sensible defaults.

Requires a template flag and a directory argument.

When used:

- TailwindCSS is added only with [`--tailwind`](#--tailwind) for supported templates
- Agent skills are not installed
- The editor is not opened
- If already inside a Git repository, the command fails

```bash
npx create-video --yes --blank my-video
```

### `-y`<AvailableFrom v="4.0.439" />

Alias for `--yes`.

### `--tailwind`<AvailableFrom v="4.0.534" />

Install [TailwindCSS](/docs/tailwind) for supported templates. Works with or without `--yes`. TailwindCSS is not added by default, and templates with their own TailwindCSS setup keep it.

```bash title="Create a project with TailwindCSS"
npx create-video --yes --blank --tailwind my-video
```

### `--no-tailwind`<AvailableFrom v="4.0.439" />

Skip TailwindCSS installation. This is the default and does not affect templates with their own TailwindCSS setup.

### `--tmp`<AvailableFrom v="4.0.214" />

Create the project in a temporary directory instead of specifying a directory name.

```bash
npx create-video --yes --blank --tmp
```

### `--help`<AvailableFrom v="4.0.488" />

Print a short overview of the arguments, flags and template flags.

```bash
npx create-video --help
```

### `-h`<AvailableFrom v="4.0.488" />

Alias for `--help`.

## Non-interactive mode

By passing `--yes` (or `-y`), all prompts are skipped and the project is created with sensible defaults. This is useful for scripting and AI agents like Claude Code.

A template flag and a directory argument are required.

```bash
npx create-video --yes --blank my-video
```

When using `--yes`:

- TailwindCSS is added only with [`--tailwind`](#--tailwind) for supported templates.
- [Agent skills](/docs/ai/skills) are not installed. You can add them manually afterwards by running [`npx skills add remotion-dev/skills`](/docs/cli/skills) in the project directory.
- The editor is not opened after scaffolding.
- The command fails if you are already inside a Git repository.

### Examples

With TailwindCSS:

```bash title="Create a project with TailwindCSS"
npx create-video --yes --blank --tailwind my-video
```

In a temporary directory:

```bash
npx create-video --yes --blank --tmp
```
