Some Remotion packages and third-party libraries use WebGL during rendering, including [`@remotion/effects`](/docs/effects), [`@remotion/three`](/docs/three), Skia and map libraries.

## Remotion 5.0

In Remotion 5.0, WebGL works during rendering by default. The default OpenGL renderer is `angle`, with automatic fallback to `swangle`. No renderer option is needed.

Lambda and Cloud Run continue to use `swangle` by default, because they have no GPU.

## Remotion 4.0

In Remotion 4.0, enable WebGL when rendering from the CLI:

```bash title="Terminal"
npx remotion render --gl=angle
```

To use `angle` by default for Studio and CLI renders, set it in `remotion.config.ts`:

```ts twoslash title="remotion.config.ts"
import {Config} from '@remotion/cli/config';
// ---cut---
Config.setChromiumOpenGlRenderer('angle');
```

See [`Config.setChromiumOpenGlRenderer()`](/docs/config#setchromiumopenglrenderer) and the [`--gl` flag reference](/docs/gl-options) for more renderer options.
