# Motion blur

Motion blur is an essential, albeit expensive effect used in video editing and motion graphics.  
It samples frames from before and after the current time and blends them together.

Remotion supports motion blur on [arbitrary content](#htmlincanvasmotionblur) through [`@remotion/motion-blur`](/docs/motion-blur/api).  
[For transitions](#motion-blur-on-transitions) there is an optimized way available in [`@remotion/transitions`](/docs/transitions).

## Programmatically

### `<HtmlInCanvasMotionBlur>`

[`<HtmlInCanvasMotionBlur>`](/docs/motion-blur/html-in-canvas-motion-blur) is Remotion's state-of-the-art implementation of motion blur.  
It requires [HTML-in-canvas](/docs/html-in-canvas#enabling-the-flag-in-chrome) to be enabled during preview.

### Motion blur on transitions<AvailableFrom v="4.0.545" />

Use [`motionBlur`](/docs/transitions/transitionseries#motionblur) on a [`<TransitionSeries.Transition>`](/docs/transitions/transitionseries#transitionseriestransition) to blur the presentations movement.

<Demo type="transition-motion-blur" />

```tsx twoslash title="MyComposition.tsx"
import {springTiming, TransitionSeries} from '@remotion/transitions';
import {slide} from '@remotion/transitions/slide';
import {AbsoluteFill} from 'remotion';

export const MyComposition = () => {
  return (
    <TransitionSeries>
      <TransitionSeries.Sequence durationInFrames={60}>
        <AbsoluteFill style={{backgroundColor: '#0b84f3'}} />
      </TransitionSeries.Sequence>
      <TransitionSeries.Transition
        presentation={slide({direction: 'from-bottom'})}
        timing={springTiming({durationInFrames: 20})}
        motionBlur={{shutterAngle: 180, samples: 16}}
      />
      <TransitionSeries.Sequence durationInFrames={60}>
        <AbsoluteFill style={{backgroundColor: '#2ecc71'}} />
      </TransitionSeries.Sequence>
    </TransitionSeries>
  );
};
```

All built-in presentations support motion blur.  
Custom presentations must be implemented using [HTML-in-canvas](/docs/transitions/presentations/custom-html-in-canvas) in order to support motion blur.

## Browser support

Preview requires HTML-in-canvas support. Browsers without it show the original presentation and a “Motion blur is not visible” indication. Rendering requires HTML-in-canvas support and uses Remotion's bundled browser by default. [HTML-in-canvas setup](/docs/html-in-canvas#enabling-the-flag-in-chrome)

## `<CameraMotionBlur>` and `<Trail>`

There are 2 more ways motion blur can be achieved in Remotion, but it is not recommended anymore:

- [`<CameraMotionBlur>`](/docs/motion-blur/camera-motion-blur) works in browsers that don't have HTML-in-canvas enabled, but layered blending can change colors and opacity.
- [`<Trail>`](/docs/motion-blur/trail) repeats earlier positions behind the current one.

## Shutter angle

Shutter angle is the exposure duration as a fraction of one frame.  
`360°` equals 1 frame, `180°` is half a frame, `90°` is a quarter of a frame, and so on.

The equivalent exposure time in seconds is `(shutterAngle / 360) / fps`.

The `samples` setting controls how many snapshots are averaged within that interval. Increasing it smooths the blur and increases rendering work.
