# Motion blur

Motion blur is an essential, albeit expensive effect used in video editing and motion graphics.  
It duplicates a frame multiple times and blends it together.

Remotion supports Motion Blur on arbitrary content in the [`@remotion/motion-blur`](/docs/motion-blur/api) package and for transitions through [`@remotion/transitions`](/docs/transitions).

## Recommended: HTML-in-canvas motion blur

[`<HtmlInCanvasMotionBlur>`](/docs/motion-blur/html-in-canvas-motion-blur) is the state-of-the-art implementation of motion blur.

## Transition motion blur<AvailableFrom v="4.0.545" />

The `motionBlur` prop on `<TransitionSeries.Transition>` blurs the presentation's movement. It is available in `@remotion/transitions`. [API reference](/docs/transitions/transitionseries#motionblur)

The demo plays at quarter speed.

<Demo type="transition-motion-blur" />

```tsx twoslash title="MyComposition.tsx"
import {springTiming, TransitionSeries} from '@remotion/transitions';
import {slide} from '@remotion/transitions/slide';
import {AbsoluteFill} from 'remotion';

export const MyComposition = () => {
  return (
    <TransitionSeries>
      <TransitionSeries.Sequence durationInFrames={60}>
        <AbsoluteFill style={{backgroundColor: '#0b84f3'}} />
      </TransitionSeries.Sequence>
      <TransitionSeries.Transition
        presentation={slide({direction: 'from-bottom'})}
        timing={springTiming({durationInFrames: 20})}
        motionBlur={{shutterAngle: 180, samples: 16}}
      />
      <TransitionSeries.Sequence durationInFrames={60}>
        <AbsoluteFill style={{backgroundColor: '#2ecc71'}} />
      </TransitionSeries.Sequence>
    </TransitionSeries>
  );
};
```

Both scenes keep advancing during the transition. Each scene is captured once at the current frame. The captured images are reused while the presentation is drawn at fractional times across the shutter interval, using the transition's timing function. The resulting images are averaged.

Animations and videos inside the scenes are sampled at the current frame. For temporal sampling of scene contents, use `<HtmlInCanvasMotionBlur>`. [Component reference](/docs/motion-blur/html-in-canvas-motion-blur)

### `motionBlur?`

An object with the following options. Passing `{}` uses the defaults. Omitting `motionBlur` disables transition motion blur.

#### `shutterAngle?`

The exposure length, expressed as an angle from `0` to `360`. Defaults to `180`, which spans half a frame centered on the current frame. At `0`, the presentation is drawn once at the current frame.

#### `samples?`

The number of presentation images to average. Defaults to `16`. Must be a positive integer. Higher values make the blur smoother and increase the rendering work.

### Supported presentations

All built-in presentations support `motionBlur`, including `slide()`, `fade()`, `wipe()`, `flip()`, `cube()`, `clockWipe()`, `iris()`, `none()`, and `pushCut()`. Their direction, perspective, mask dimensions, fade-out, and push-cut options are preserved. [Presentation reference](/docs/transitions/presentations)

CSS style overrides such as `enterStyle`, `exitStyle`, `innerEnterStyle`, `innerExitStyle`, `outerEnterStyle`, and `outerExitStyle` require the React rendering path. Combining them with `motionBlur` throws an error.

Custom presentations can provide a `canvas` renderer with the `HtmlInCanvasShader<Props>` interface. Presentations created with `makeHtmlInCanvasPresentation()` expose their shader automatically. Each draw must produce a complete image for the supplied progress value independently of earlier draws. [Shader API](/docs/transitions/make-html-in-canvas-presentation)

### Sequence boundaries

Transition motion blur requires a `<TransitionSeries.Sequence>` on both sides of the transition. The entering and exiting transitions of a middle sequence must fit within its duration without overlapping.

Exposure samples are clamped to the transition duration. Scene mounting follows the current frame, so samples near a sequence boundary can differ from temporal sampling of the full scene.

### Browser support

Preview requires HTML-in-canvas support. Browsers without it show the original presentation and a “Motion blur is not visible” indication. Rendering requires HTML-in-canvas support and uses Remotion's bundled browser by default. [HTML-in-canvas setup](/docs/html-in-canvas#enabling-the-flag-in-chrome)

## `<CameraMotionBlur>` and `<Trail>`

There are 2 more ways motion blur can be achieved in Remotion, but it is not recommended anymore:

[`<CameraMotionBlur>`](/docs/motion-blur/camera-motion-blur) works in browsers that don't have HTML-in-canvas enabled, but layered blending can change colors and opacity.

[`<Trail>`](/docs/motion-blur/trail) repeats earlier positions behind the current one.

## Explaining "shutter angle"

The name comes from film cameras with a rotating shutter disc. The angle of its open sector determines how long each frame is exposed.

Shutter angle describes the exposure duration as a fraction of one frame. A full turn is `360°`, so `180°` covers half a frame. Larger angles produce longer motion streaks, while smaller angles make movement appear sharper.

The equivalent exposure time in seconds is `(shutterAngle / 360) / fps`.

| Shutter angle | Exposure in frames | Exposure at 30 FPS |
| ------------- | ------------------ | ------------------ |
| `90°`         | Quarter of a frame | `1/120` second     |
| `180°`        | Half a frame       | `1/60` second      |
| `360°`        | One frame          | `1/30` second      |

For `<HtmlInCanvasMotionBlur>` and transition motion blur, `0°` renders the current instant and `180°` is the default. At 60 FPS, the same `180°` angle corresponds to `1/120` second, so faster frame rates produce shorter streaks for the same movement per second.

`<HtmlInCanvasMotionBlur>` and transition motion blur center the exposure on the current frame. At `180°`, samples span from a quarter-frame before the current frame to a quarter-frame after it.

The `samples` setting controls how many snapshots are averaged within that interval. Increasing it smooths the blur and increases rendering work. The shutter angle controls the interval's length.
