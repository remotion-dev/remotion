# Motion blur

To realize a realistic motion blur, a frame needs to be duplicated multiple times and blended together.

Remotion provides a [`@remotion/motion-blur`](/docs/motion-blur/api) package to achieve this.

Ask an agent with [Remotion Skills](/docs/ai/skills) installed to add motion blur to a component:

<SuggestedPrompt prompt="/remotion-markup Add motion blur to my text animation" />

## Recommended: HTML-in-canvas motion blur

[`<HtmlInCanvasMotionBlur>`](/docs/motion-blur/html-in-canvas-motion-blur) is the state-of-the-art implementation of motion blur.

It requires [HTML-in-canvas](/docs/html-in-canvas#enabling-the-flag-in-chrome) to be enabled during preview. Rendering needs no configuration.

<Demo type="motion-blur-html-in-canvas" />

## Camera motion blur

[`<CameraMotionBlur>`](/docs/motion-blur/camera-motion-blur) works in browsers that don't have HTML-in-canvas enabled, but layered blending can change colors and opacity.

<Demo type="motion-blur-camera" />

Set `shutterAngle` to control the exposure length and `samples` to control smoothness.

## Trail

[`<Trail>`](/docs/motion-blur/trail) repeats earlier positions behind the current one.

It does not aim to reproduce a realistic camera exposure.
