# addElement()<AvailableFrom v="4.0.530" />

Inserts an element created with [`createElement()`](/docs/codemods/create-element) into a composition component or relative to an existing node, and adds the imports it needs.

:::warning

_Draft API_: This API is experimental and may change.

:::

```ts twoslash title="add-element.ts"
import {addElement, createElement, type CodemodProject} from '@remotion/codemods';

declare const project: CodemodProject;

const result = addElement({
  project,
  element: createElement({
    component: 'Solid',
    importPath: 'remotion',
    props: {width: 1920, height: 1080, color: 'gray'},
  }),
  target: {
    type: 'composition',
    compositionFile: 'src/Root.tsx',
    compositionId: 'MyComposition',
  },
});

console.log(result.changes);
console.log(result.insertedNode);
```

To place the element on the timeline, wrap it in a [`<Sequence>`](/docs/sequence):

```ts twoslash title="add-timed-element.ts"
import {addElement, createElement, type CodemodProject} from '@remotion/codemods';

declare const project: CodemodProject;

const video = createElement({
  component: 'Video',
  importPath: '@remotion/media',
  props: {src: 'https://example.com/video.mp4'},
});

const result = addElement({
  project,
  element: createElement({
    component: 'Sequence',
    importPath: 'remotion',
    props: {from: 30, durationInFrames: 90},
    children: [video],
  }),
  target: {
    type: 'composition',
    compositionFile: 'src/Root.tsx',
    compositionId: 'MyComposition',
  },
});
```

Media files are not copied or downloaded, metadata is not probed, and packages are not installed. The project must already contain the dependencies needed by the generated imports.

From v4.0.544, all supported insertion paths are synchronous, including SVG conversion and file-backed insertion.

## Options

### project

An in-memory [`CodemodProject`](/docs/codemods#project-model). The input project is not mutated.

### element

The element to insert, created with [`createElement()`](/docs/codemods/create-element), or an `AddElementDescriptor` (from v4.0.544).

Descriptors support `solid`, `text`, `asset`, `component`, `track`, `svg`, and `composition` types. SVG and composition descriptors require a `composition` target.

```ts twoslash title="add-asset.ts"
import {addElement, type CodemodProject} from '@remotion/codemods';
declare const project: CodemodProject;
// ---cut---
const result = addElement({
  project,
  element: {
    type: 'asset', assetType: 'image', src: 'logo.png', srcType: 'static',
    dimensions: {width: 320, height: 180}, durationInFrames: null, position: null,
  },
  from: 30,
  target: {type: 'composition', compositionFile: 'src/Root.tsx', compositionId: 'MyComposition'},
});
```

#### type

The descriptor kind. Use `'asset'` for media, `'component'` for a named component import, `'solid'` for a gray rectangle, `'text'` for editable text, or `'track'` for an empty Track. `'svg'` converts SVG markup; `'composition'` inserts another registered composition.

#### position

An `{x, y}` canvas position, or `null`. Empty Track descriptors require `null`.

#### assetType

For assets: `'image'`, `'video'`, `'audio'`, `'gif'`, or `'animated-image'`.

#### src

The asset path or URL.

#### srcType

`'static'` for a public-folder path or `'remote'` for a URL.

#### dimensions

Asset dimensions as `{width, height}`, or `null`.

#### durationInFrames

The asset duration, or `null`. Composition descriptors require a duration.

#### width

The Solid or composition width.

#### height

The Solid or composition height.

#### text

The text content for a text descriptor.

#### fontSize

The font size for a text descriptor.

#### color

The CSS text color.

#### componentName

The JSX name for a component descriptor.

#### importName

The exported component name.

#### importPath

The module exporting the component.

#### props

An array of `{name, value}` props for the component.

#### markup

SVG descriptors contain the SVG source string.

#### compositionFile

The file registering the composition to insert.

#### compositionId

The ID of the composition to insert.

#### serializedResolvedPropsWithCustomSchema

Serialized resolved props for the composition. Composition descriptors also require `durationInFrames`, `width`, and `height`.

### target

Where to insert the element. One of the following objects.

#### `{type: 'composition', compositionFile, compositionId}`

Appends the element to the component of the composition with the static ID `compositionId`, registered in `compositionFile`. The component may be imported from another project file. If the component returns a single element, both are grouped in a fragment. If it returns `null`, the element becomes its content.

#### `{type: 'component', filePath, exportName}`

Appends the element to the root returned by the component that `filePath` exports as `exportName`, or as its default export when `exportName` is `'default'`. Use it when the component is already known, for example from [`resolveCompositionComponent()`](/docs/codemods/resolve-composition-component). Follows the same rules as the `composition` target.

#### `{type: 'inside', node}`

Appends the element as the last child of `node`. Self-closing elements are expanded.

#### `{type: 'before', node}`

Inserts the element before `node`. If the node has no parent element, for example because it is returned directly, both are grouped in a fragment.

#### `{type: 'after', node}`

Inserts the element after `node`, following the same rules as `before`.

Obtain a `node` from [`getNodes()`](/docs/codemods/get-nodes) or a previous result. See [node references](/docs/codemods#node-references).

#### `{type: 'track', node, from, durationInFrames}`<AvailableFrom v="4.0.544" />

Inserts the element into a Track, wrapped in a Sequence with the specified start and duration. `node` must refer to a Track. `from` must be finite and nonnegative; `durationInFrames` must be finite and positive.

### environment?<AvailableFrom v="4.0.544" />

A [file-backed source environment](/docs/codemods#file-backed-sources) to use instead of `project`. Reads only the source files needed for the operation. Both source modes return file changes without writing them.

### from?<AvailableFrom v="4.0.544" />

Start frame for an element descriptor. Must be a nonnegative integer. Defaults to `null`. A Solid gets a Sequence wrapper; other descriptors receive their timing through their supported props.

### wrapInSequence?<AvailableFrom v="4.0.544" />

Wraps an element descriptor in a Sequence. Defaults to `null`. Accepts `from`, `durationInFrames`, `name`, `dimensions`, and `position`, each nullable. Track targets provide their own wrapper.

### svgMarkupToJsx?<AvailableFrom v="4.0.544" />

Converts SVG markup to a parsed JSX element for an SVG descriptor with an in-memory `project`. With `environment`, its `svgMarkupToJsx` callback is used instead. The callback is not invoked for other descriptor types.

### prettierConfigOverride?

Formatting options for generated source, such as `singleQuote`, `useTabs`, `tabWidth`, `printWidth`, and `bracketSpacing`. Defaults to `null`, which follows the existing source style.

## Return value

An object with the following properties.

### changes

An array of `{filePath, previousContents, nextContents}` file changes.

### nodePathRemappings

An array of `{filePath, oldNodePath, newNodePath}` mappings. A `null` old path indicates an insertion; a `null` new path indicates removal. Every inserted element, including children of the inserted element, is listed with a `null` old path. See [node references](/docs/codemods#node-references).

### insertedNode

The reference of the outermost inserted element. Use [`getNodes()`](/docs/codemods/get-nodes) and its `parentNodePath` to find inserted children.

## Errors

Throws when the target cannot be resolved, the composition component cannot receive content, or the element is invalid. Failed edits leave the input project unchanged.
