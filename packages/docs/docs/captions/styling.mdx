# Styling captions

Captions in Remotion can be styled however you like using HTML and CSS.  
Or you can use pre-made caption styles:

- [Remotion Elements - Captions](/elements/captions/)
- [Remocn - Captions](https://remocn.dev/docs/captions/getting-started/introduction#all-caption-styles)

## Choose a style when transcribing<AvailableFrom v="4.0.535" />

If you [transcribe](/docs/captions/transcribing) a video or audio in the [Studio](/docs/studio), you get the chance to choose a preset by picking from caption [elements](/docs/elements).

<Step>1</Step> Select a video or audio layer and click `Generate captions` in the inspector.
