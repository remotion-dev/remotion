# Editing captions

If you need to make a correction to the transcript, you can edit [captions](/docs/captions).

## Interactively in Studio {#edit-text-in-studio}

[If set up the right way](/docs/captions/displaying#make-captions-editable-in-studio), captions appear as orange layers in the Studio timeline.

### Add a page break

Click the <EnterIcon role="img" aria-label="Break after this" color="currentColor" width={16} height={16} style={{verticalAlign: 'middle'}} /> icon on a caption row to [start a new page with the next caption](/docs/captions/caption#pagebreakafter).

### Split a caption

Place the cursor where the caption should split and press <kbd>Enter</kbd>.

### Replace the transcript

Select the caption layer and click the <UploadIcon role="img" aria-label="Import transcript" color="currentColor" width={14} height={14} style={{verticalAlign: 'middle'}} /> icon next to `Captions`. The following formats are supported:

- `.srt`
- `.json` with [`Caption[]`](/docs/captions/caption) array
- [ElevenLabs transcript](/docs/elevenlabs/detect-elevenlabs-transcript-format)
- [OpenAI Whisper verbose JSON transcript](/docs/openai-whisper/is-openai-whisper-transcript)
