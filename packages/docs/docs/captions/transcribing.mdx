# Transcribing audio

You can transcribe video or audio in the [Studio](/docs/studio), with the CLI, or in the browser on [remotion.dev/transcribe](https://www.remotion.dev/transcribe).

## In the Studio

<Step>1</Step> Select a video or audio layer.<br />
<Step>2</Step> Click <code>Generate captions</code> in the inspector.

From v4.0.535, you can select a style from [caption Elements](/elements/captions/) in the <code>Styles</code> tab. See [Styling captions](/docs/captions/styling).

## With the CLI

[`npx remotion whisper transcribe`](/docs/cli/whisper/transcribe) transcribes a local audio or video file.

```bash title="Transcribe a file"
npx remotion whisper transcribe public/interview.mp4
```

## On remotion.dev/transcribe

[remotion.dev/transcribe](https://www.remotion.dev/transcribe) transcribes audio and video locally in the browser.

## Packages

Remotion maintains several options for transcribing audio to generate captions:

- **[`@remotion/whisper-webgpu`](/docs/whisper-webgpu) - Transcribe in the browser, Node.js or Bun using WebGPU**
- [`@remotion/install-whisper-cpp`](/docs/install-whisper-cpp) - Transcribe audio locally on a server using [Whisper.cpp](https://github.com/ggerganov/whisper.cpp)
- [`@remotion/openai-whisper`](/docs/openai-whisper) - Use the OpenAI Whisper API for cloud-based transcription
- [`@remotion/elevenlabs`](/docs/elevenlabs) - Use the ElevenLabs Speech to Text API for cloud-based transcription

## Comparison

|                        | [`@remotion/whisper-webgpu`](/docs/whisper-webgpu) | [`@remotion/install-whisper-cpp`](/docs/install-whisper-cpp) | [`@remotion/openai-whisper`](/docs/openai-whisper)                                    | [`@remotion/elevenlabs`](/docs/elevenlabs)                                               |
| ---------------------- | -------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Environment**        | Browser, Node.js, Bun                              | Node.js, Bun                                                 | Cloud (API)                                                                           | Cloud (API)                                                                              |
| **Speed**              | Fast (depends on GPU)                              | Fast (depends on hardware)                                   | Fast                                                                                  | Fast                                                                                     |
| **Cost**               | Free                                               | Free                                                         | Paid (OpenAI API pricing)                                                             | Paid (ElevenLabs API pricing)                                                            |
| **Offline support**    | ✅                                                 | ✅                                                           | ❌                                                                                    | ❌                                                                                       |
| **No server needed**   | ✅                                                 | ❌                                                           | ✅                                                                                    | ✅                                                                                       |
| **Convert function**   | [`toCaptions()`](/docs/whisper-webgpu/to-captions) | [`toCaptions()`](/docs/install-whisper-cpp/to-captions)      | [`openAiWhisperApiToCaptions()`](/docs/openai-whisper/openai-whisper-api-to-captions) | [`elevenLabsTranscriptToCaptions()`](/docs/elevenlabs/elevenlabs-transcript-to-captions) |
| **Our recommendation** | ✅                                                 |                                                              |                                                                                       |                                                                                          |

All of these options can output captions in the [`Caption`](/docs/captions/caption) type format, which is recommended for use with Remotion.
