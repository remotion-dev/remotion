# Captions

You can work with captions in Remotion very dynamically.  
Use TypeScript to process data and HTML and CSS to style them however you like.

We have created a standardized [`Caption`](/docs/captions/caption) type and built resources around it, so you don't have to reinvent the wheel for common caption operations.

This guide revolves around the [`Caption`](/docs/captions/caption) type and explains best practices for how to import, export, transcribe, edit, style and layout captions in your Remotion.
