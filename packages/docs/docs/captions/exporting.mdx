# Exporting subtitles

The following ways are available for exporting [captions](/docs/captions) in Remotion.

## Burned-in subtitles

If you want the subtitles to be part of the video itself (burned in), [render the video](/docs/render) as usual.

```bash
npx remotion render
```

## Exporting all captions as `.srt`

To automatically merge all subtitles from from components [which implement `captionsSchema`](/docs/captions/displaying#make-captions-editable-in-studio) and export them as a single `.srt` file is not yet possible.

[Follow this issue](https://github.com/remotion-dev/remotion/issues/13597) to get notified when we implement this.

## Emitting a .srt file alongside the render

If you keep your captions in one place and collect them manually, you can emit a separate `.srt` file using the [`<Artifact>`](/docs/artifact) component together with [`serializeSrt()`](/docs/captions/serialize-srt).

```tsx twoslash title="Exporting captions as .srt"
import {createTikTokStyleCaptions, serializeSrt} from '@remotion/captions';
import {Artifact, useCurrentFrame} from 'remotion';
import type {Caption} from '@remotion/captions';

const captions: Caption[] = [
  {
    text: 'Hello',
    startMs: 0,
    endMs: 500,
    timestampMs: 250,
    confidence: 1,
  },
  {
    text: ' world!',
    startMs: 500,
    endMs: 1000,
    timestampMs: 750,
    confidence: 1,
  },
];

// ---cut---
const {pages} = createTikTokStyleCaptions({
  captions,
  combineTokensWithinMilliseconds: 3000,
});

const srtContent = serializeSrt({
  lines: pages.map(({tokens}) =>
    tokens.map(({text, fromMs, toMs}) => ({
      text,
      startMs: fromMs,
      endMs: toMs,
      timestampMs: null,
      confidence: null,
    })),
  ),
});

export const MyComp = () => {
  const frame = useCurrentFrame();

  return (
    <>
      {frame === 0 ? <Artifact filename="subtitles.srt" content={srtContent} /> : null}
      {/* Rest of your video content */}
    </>
  );
};
```

The artifact will be saved to `out/[composition-id]/subtitles.srt` when rendering.

## Show captions only in previews

Use `isRendering` from [`useRemotionEnvironment()`](/docs/use-remotion-environment) to keep captions visible in Studio and the Player while leaving them out of the rendered video.

```tsx twoslash title="MyVideo.tsx"
// @filename: SimpleCaptions.tsx
import type {ComponentType} from 'react';

export declare const SimpleCaptions: ComponentType;

// @filename: MyVideo.tsx
// ---cut---
import {Video} from '@remotion/media';
import {staticFile, useRemotionEnvironment} from 'remotion';
import {SimpleCaptions} from './SimpleCaptions';

export const MyVideo = () => {
  const {isRendering} = useRemotionEnvironment();

  return (
    <>
      <Video src={staticFile('video.mp4')} />
      {isRendering ? null : <SimpleCaptions />}
    </>
  );
};
```
