By default, a Remotion Lambda function has the following naming convention:

```diff
remotion-render-4-0-372-mem2048mb-disk2048mb-240sec
                ^^^^^^^    ^^^^       ^^^^   ^^^
                  |         |          |      |-- Timeout in seconds
                  |         |          |--------- Disk size in MB
                  |         |------------------- Memory size in MB
                  |----------------------------- Remotion version with dots replaced by dashes
```

When you deploy a function without a name override, the name is generated from its configuration. This has two benefits:

<Step>1</Step> Avoid having multiple functions with the same configuration unnecessarily.<br/>
<Step>2</Step> Being able to guess the function name using <a href="/docs/lambda/speculatefunctionname">
  <code>speculateFunctionName()</code>
</a> so you don't have to fetch a list of functions in your AWS account.

## Overriding the convention<AvailableFrom v="4.0.540" />

See [Custom Lambda function names](/docs/lambda/custom-function-names) for how to bypass the default naming convention, only recommended if you need to due to organizational requirements.
