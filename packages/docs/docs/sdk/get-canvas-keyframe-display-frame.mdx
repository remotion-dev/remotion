# getCanvasKeyframeDisplayFrame()<AvailableFrom v="4.0.530" />

Converts a frame of a prop's `interpolate()` expression to a composition frame. It is the inverse of [`getCanvasKeyframeSourceFrame()`](/docs/sdk/get-canvas-keyframe-source-frame).

:::warning

_Experimental API_: This package is not stable. Its public API may change without a major version bump.

:::

```ts twoslash title="seek-to-keyframe.ts"
// @moduleResolution: bundler
import {getCanvasKeyframeDisplayFrame, type TimelineTrackData} from '@remotion/sdk';
import type {CanUpdateSequencePropStatus} from 'remotion';
declare const track: TimelineTrackData;
declare const propStatus: CanUpdateSequencePropStatus;
declare const seek: (frame: number) => void;
// ---cut---
export const seekToKeyframe = (sourceFrame: number) => {
  seek(getCanvasKeyframeDisplayFrame({track, propStatus, sourceFrame}));
};
```

## Parameters

An object with the following properties:

### track

The `TimelineTrackData` of the sequence from [`controller.timeline`](/docs/sdk/create-canvas-controller#timeline). Only `keyframeDisplayOffset` and `keyframePlaybackRate` are read.

### propStatus

How the prop is written in the source, as the `props` of [`getNodeProps()`](/docs/codemods/get-node-props) report it, or `null`.

### sourceFrame

A frame in the clock of the interpolation, for example the `frame` of a keyframe in a `'keyframed'` prop status.

## Return value

The composition frame at which the keyframe applies. It may be fractional when the sequence has a `playbackRate`.
