# Interactive.withSchema()<AvailableFrom v="4.0.530" />

Wraps a React component so Remotion Studio shows it as interactive.

```tsx twoslash title="Circle.tsx"
import type React from 'react';
import {Interactive, type InteractivitySchema} from 'remotion';

type CircleProps = {
  readonly radius?: number;
  readonly color?: string;
  readonly style?: React.CSSProperties;
};

const circleSchema = {
  radius: {
    type: 'number',
    min: 1,
    step: 1,
    default: 80,
    description: 'Radius',
    hiddenFromList: false,
  },
  color: {
    type: 'color',
    default: '#0b84ff',
    description: 'Color',
  },
  ...Interactive.transformSchema,
} as const satisfies InteractivitySchema;

const CircleInner: React.FC<CircleProps> = ({radius = 80, color = '#0b84ff', style}) => {
  return (
    <div
      style={{
        ...style,
        width: radius * 2,
        height: radius * 2,
        borderRadius: '50%',
        backgroundColor: color,
      }}
    />
  );
};

export const Circle = Interactive.withSchema({
  Component: CircleInner,
  componentName: '<Circle>',
  schema: circleSchema,
});
```

The exported `Circle` component accepts `CircleProps`, [timing props](/docs/timing), [premount props](/docs/interactive#interactivepremountprops) and [cropping props](/docs/interactive#interactivecropprops).

## API

```ts twoslash
import {Interactive} from 'remotion';
```

The options for `Interactive.withSchema()` are:

### `Component`

The component to wrap.

It must accept a `style?: React.CSSProperties` prop and apply it to its visual root.

### `componentName`

The component name used by Studio and in validation messages.

### `defaultDurationInFrames?`<AvailableFrom v="4.0.530" />

Sets the default [`<Sequence>`](/docs/sequence) duration when no `durationInFrames` prop is passed.

### `schema`

An [`InteractivitySchema`](/docs/interactivity-schema) that describes which props are editable in Remotion Studio.

`Interactive.withSchema()` includes [`Interactive.baseSchema`](/docs/interactive#interactivebaseschema), [`Interactive.premountSchema`](/docs/interactive#interactivepremountschema) and [`Interactive.cropSchema`](/docs/interactive#interactivecropschema).

Use [`Interactive.transformSchema`](/docs/interactive#interactivetransformschema) if the component should expose transform controls.

For reliable source updates, follow [Interactivity best practices](/docs/studio/interactivity-best-practices): Keep editable values inline, use hardcoded `interpolate()` keyframe arrays, use `translate`, `scale`, `rotate` and `opacity` directly, and avoid animated layout props or `transform` strings.

### Return value

Returns a component with the public props of `Component`, the common [timing props](/docs/timing), [`InteractivePremountProps`](/docs/interactive#interactivepremountprops) and [`InteractiveCropProps`](/docs/interactive#interactivecropprops).

The premount props are `premountFor`, `postmountFor`, `styleWhilePremounted` and `styleWhilePostmounted`. In v4, `premountFor` defaults to `0`. From [v5.0](/docs/5-0-migration), it defaults to one second (`fps` frames). Pass `premountFor={0}` to opt out. `postmountFor` defaults to `0`.

The cropping props are `cropLeft`, `cropRight`, `cropTop` and `cropBottom`. Each value is a ratio from `0` to `1` of the corresponding width or height: `0` leaves the edge unchanged and `1` crops it fully.

The returned component merges the incoming `style`, the active premounting or postmounting style, and then the crop style before passing it to `Component`. The crop `clipPath` therefore replaces an earlier inline `style.clipPath`. It renders `Component` inside a [`<Sequence layout="none">`](/docs/sequence).

### Ref forwarding<AvailableFrom v="4.0.530" />

If `Component` accepts a ref, the returned component preserves its ref type and forwards the ref directly to `Component`.

## Behavior

During rendering, in the Player and in read-only Studio sessions, `Interactive.withSchema()` uses the original editable values and applies timing and cropping. In the Player and Studio, it also applies premounting and postmounting styles and freezes the component at its first or last local frame while it is premounted or postmounted. Premounting and postmounting do not apply during rendering.

In editable Studio sessions, it reads the current prop values, applies timeline overrides and passes the merged props to the inner component.
