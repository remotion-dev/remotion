# loadVideoMattingModel()<AvailableFrom v="4.0.523" />

Initializes a previously downloaded video matting model on WebGPU. Call [`downloadVideoMattingModel()`](/docs/video-matting/download-video-matting-model) first.

Call it before [`separateVideoLayers()`](/docs/video-matting/separate-video-layers).

```ts twoslash title="load-model.ts"
import {downloadVideoMattingModel, loadVideoMattingModel} from '@remotion/video-matting';

await downloadVideoMattingModel({model: 'modnet'});
await using result = await loadVideoMattingModel({
  model: 'modnet',
});

console.log(result.alreadyLoaded);
```

## Options

### model

One of the names returned by [`getAvailableModels()`](/docs/video-matting/get-available-models).

### onProgress?

Called while the cached model is initialized. Use [`downloadVideoMattingModel()`](/docs/video-matting/download-video-matting-model) for download progress. Default: no callback.

The callback receives these properties:

#### status

The current model-loading status.

#### file

The model file associated with the update, or `null` for aggregate progress.

#### progress

`null` during initialization and `1` when ready.

#### loadedBytes

Always `null`; downloads happen in [`downloadVideoMattingModel()`](/docs/video-matting/download-video-matting-model).

#### totalBytes

Always `null`.

## Return value

Returns an object with this property:

### alreadyLoaded

Whether the same model was already initialized in memory.

### `[Symbol.asyncDispose]()`<AvailableFrom v="4.0.528" />

Releases resources allocated by this function.

Use `await using` to call this method automatically when leaving the current scope.

Call [`disposeVideoMattingModel()`](/docs/video-matting/dispose-video-matting-model) to dispose the pipeline explicitly regardless of retained load handles.
