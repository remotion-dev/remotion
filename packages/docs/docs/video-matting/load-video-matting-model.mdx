# loadVideoMattingModel()<AvailableFrom v="4.0.523" />

Downloads a video matting model from an immutable path on `remotion.media` and initializes it. Calling it before [`separateVideoLayers()`](/docs/video-matting/separate-video-layers) lets you show model-loading progress.

```ts twoslash title="load-model.ts"
import {loadVideoMattingModel} from '@remotion/video-matting';

await using result = await loadVideoMattingModel({
  model: 'modnet',
  onProgress: ({progress}) => {
    console.log(progress);
  },
});

console.log(result.alreadyLoaded);
```

## Options

### model

One of the names returned by [`getAvailableModels()`](/docs/video-matting/get-available-models).

### onProgress?

Called while model files are resolved and downloaded. Default: no callback.

The callback receives these properties:

#### status

The current model-loading status.

#### file

The model file associated with the update, or `null` for aggregate progress.

#### progress

Download progress between `0` and `1`, or `null` when it cannot be calculated.

#### loadedBytes

The number of bytes downloaded, or `null` when it is unknown.

#### totalBytes

The total number of bytes, or `null` when it is unknown.

## Return value

Returns an object with this property:

### alreadyLoaded

Whether the same model was already initialized in memory.

### `[Symbol.asyncDispose]()`<AvailableFrom v="4.0.527" />

Releases this call's hold on the initialized model. The pipeline is disposed after every load handle is released and active separations finish.

Use `await using` to call this method automatically when leaving the current scope. Call [`disposeVideoMattingModel()`](/docs/video-matting/dispose-video-matting-model) to dispose the pipeline explicitly regardless of retained load handles.

The browser manages the persistent [Transformers.js](https://huggingface.co/docs/transformers.js) cache. Releasing the initialized pipeline does not delete the downloaded model files.

The hosted files are byte-identical to files from the pinned upstream Hugging Face revision.
