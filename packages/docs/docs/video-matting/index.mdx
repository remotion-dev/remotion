# @remotion/video-matting<AvailableFrom v="4.0.523" />

## Example

```ts twoslash title="separate-video.ts"
import {
  downloadVideoMattingModel,
  loadVideoMattingModel,
  separateVideoLayers,
} from '@remotion/video-matting';

export const matteVideo = async (file: File) => {
  const model = 'modnet';
  await downloadVideoMattingModel({
    model,
    onProgress: ({progress}) => console.log('Downloading model:', progress),
  });
  await using modelHandle = await loadVideoMattingModel({
    model,
  });
  console.log('Model already in memory:', modelHandle.alreadyLoaded);

  await using layers = await separateVideoLayers({
    src: file,
    model,
    onProgress: ({progress}) => console.log('Separating layers:', progress),
  });

  const [baseBlob, foregroundBlob] = await Promise.all([
    layers.base.getBlob(),
    layers.foreground.getBlob(),
  ]);

  return {baseBlob, foregroundBlob};
};
```

Pass a `File` from a file input to `matteVideo()`. On return, `await using` releases the model from memory and removes temporary output files. The returned blobs remain usable, and downloaded model files stay cached for future runs.

## Model hosting

Model files are downloaded from immutable paths on `remotion.media`. We find that downloads are faster from a R2 mirror than from Hugging Face directly. The models are byte-identical to the ones you can find from Hugging Face.

## Requirements

WebGPU requires HTTPS in production or `localhost` during development. Use [`canUseVideoMatting()`](/docs/video-matting/can-use-video-matting) to check whether the selected model is supported.

If the page uses a strict Content Security Policy, add `https://remotion.media` to its `connect-src` directive, for example `connect-src 'self' https://remotion.media`.

The browser must also be able to decode the input video and encode VP9 with alpha through WebCodecs. [`separateVideoLayers()`](/docs/video-matting/separate-video-layers) checks these media capabilities for the selected input.
