# @remotion/video-matting<AvailableFrom v="4.0.523" />

Separate a video into background and foreground layers, locally in the browser or [Node.js](/docs/video-matting/node) using WebGPU.

## Example

```ts twoslash title="separate-video.ts"
import {
  downloadVideoMattingModel,
  loadVideoMattingModel,
  separateVideoLayers,
} from '@remotion/video-matting';

export const matteVideo = async (file: File) => {
  const model = 'modnet';
  await downloadVideoMattingModel({
    model,
    onProgress: ({progress}) => console.log('Downloading model:', progress),
  });
  await using modelHandle = await loadVideoMattingModel({
    model,
  });
  console.log('Model already in memory:', modelHandle.alreadyLoaded);

  await using layers = await separateVideoLayers({
    src: file,
    model,
    onProgress: ({progress}) => console.log('Separating layers:', progress),
  });

  const [baseBlob, foregroundBlob] = await Promise.all([
    layers.base.getBlob(),
    layers.foreground.getBlob(),
  ]);

  return {baseBlob, foregroundBlob};
};
```

## Model hosting

We noticed that hosting the models on R2 leads to faster downloading than through Hugging Face directly.  
We mirrored the models to `remotion.media`, keeping them byte-identical.  
We also notified Hugging Face and they are investigating the issue. We may migrate back to the official hosting in the future.

## Requirements

A GPU is needed for this.
Use [`canUseVideoMatting()`](/docs/video-matting/can-use-video-matting) to check whether your system can use video matting.

The browser must also be able to decode the input video and encode VP9 with alpha through WebCodecs.  
[`separateVideoLayers()`](/docs/video-matting/separate-video-layers) checks these media capabilities for the selected input.
