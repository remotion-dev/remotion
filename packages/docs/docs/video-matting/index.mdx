# @remotion/video-matting<AvailableFrom v="4.0.523" />

Remove a video's background or separate it into background and foreground layers, locally in the browser or [Node.js](/docs/video-matting/node) using WebGPU.

## Example

```ts twoslash title="remove-video-background.ts"
import {downloadVideoMattingModel, removeVideoBackground} from '@remotion/video-matting';

export const matteVideo = async (file: File) => {
  await downloadVideoMattingModel({
    model: 'modnet',
    onProgress: ({progress}) => console.log('Downloading model:', progress),
  });
  await using result = await removeVideoBackground({
    src: file,
    model: 'modnet',
    onProgress: ({progress}) => console.log('Removing background:', progress),
  });

  return result.video.getBlob();
};
```

To preserve the original video alongside the transparent result, duplicate its layer in Studio before removing the background.

## Model hosting

We noticed that hosting the models on R2 leads to faster downloading than through Hugging Face directly.  
We mirrored the models to `remotion.media`, keeping them byte-identical.  
We also notified Hugging Face and they are investigating the issue. We may migrate back to the official hosting in the future.

## Requirements

A GPU is needed for this.
Use [`canUseVideoMatting()`](/docs/video-matting/can-use-video-matting) to check whether your system can use video matting.

The browser must also be able to decode the input video and encode VP9 with alpha through WebCodecs.  
[`removeVideoBackground()`](/docs/video-matting/remove-video-background) and [`separateVideoLayers()`](/docs/video-matting/separate-video-layers) check these media capabilities for the selected input.
