# removeVideoMattingModel()<AvailableFrom v="4.0.523" />

Removes a video matting model from memory and the persistent browser cache.

If the model is still loading or separating a video, removal waits for the operation to finish.

```ts twoslash title="remove-model.ts"
import {removeVideoMattingModel} from '@remotion/video-matting';

await removeVideoMattingModel({model: 'modnet'});
```

## Options

### model

One of the names returned by [`getAvailableModels()`](/docs/video-matting/get-available-models).
