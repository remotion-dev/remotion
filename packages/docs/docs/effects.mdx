Apply effects doing pixel manipulation onto any element.  
You can use one of Remotions built-in effects or create your own.

## Supported components

The following components support effects:

- [`<Solid>`](/docs/solid)
- [`<Video>`](/docs/media/video)
- [`<Img>`](/docs/img)
- [`<CanvasImage>`](/docs/canvasimage)
- [`<AnimatedImage>`](/docs/animatedimage)
- [`<Gif>`](/docs/gif/gif)
- [`<RemotionRiveCanvas>`](/docs/rive/remotionrivecanvas)
- [`@remotion/shapes` components](/docs/shapes)

All other elements, and any HTML component can be wrapped in [`<HtmlInCanvas>`](/docs/remotion/html-in-canvas), which can then accept effects.

## Usage

Effects can be added programmatically, interactively or agentically.

### Programmatically

Pass effects through the `effects` prop as an array of effect functions:

```tsx twoslash title="MyComp.tsx"
import {Video} from '@remotion/media';
import {blur} from '@remotion/effects/blur';

export const MyComp: React.FC = () => {
  return (
    <Video
      src="https://remotion.media/video.mp4"
      effects={[blur({radius: 40})]}
    />
  );
};
```

### Interactively

In [Remotion Studio](/docs/studio), select any element.  
You then have multiple ways of adding an effect:

- Click the `+` icon in the Inspector next to `Effects`.
- Press <kbd>E</kbd>
- Right-click and select `Add Effect`
- Drag an effect from the [Effects library](/effects) onto the element.

Ask an agent with [Remotion Skills](/docs/agents/skills) installed to add an effect while following Remotion conventions:

## Multipass

Multiple effects can be combined. They apply in the order they are specified.
