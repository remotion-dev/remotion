Use [`<Video>`](/docs/media/video) and [`<Audio>`](/docs/media/audio) from [`@remotion/media`](/docs/media) to add video and sound to your composition.

## Using a local file

Put your media in the [`public` folder](/docs/terminology/public-dir) and reference it with [`staticFile()`](/docs/staticfile).

<Tabs groupId="media-type">
<TabItem value="video" label="Video">

```tsx twoslash title="MyComposition.tsx"
import {Video} from '@remotion/media';
import {staticFile} from 'remotion';

export const MyComposition = () => {
  return <Video src={staticFile('video.mp4')} />;
};
```

</TabItem>
<TabItem value="audio" label="Audio">

```tsx twoslash title="MyComposition.tsx"
import {Audio} from '@remotion/media';
import {staticFile} from 'remotion';

export const MyComposition = () => {
  return <Audio src={staticFile('audio.mp3')} />;
};
```

</TabItem>
</Tabs>

## Using a URL

Pass a remote URL as `src`. The server must allow [cross-origin requests](/docs/cors-issues).

<Tabs groupId="media-type">
<TabItem value="video" label="Video">

```tsx twoslash title="MyComposition.tsx"
import {Video} from '@remotion/media';

export const MyComposition = () => {
  return <Video src="https://remotion.media/BigBuckBunny.mp4" />;
};
```

</TabItem>
<TabItem value="audio" label="Audio">

```tsx twoslash title="MyComposition.tsx"
import {Audio} from '@remotion/media';

export const MyComposition = () => {
  return <Audio src="https://remotion.media/audio.mp3" />;
};
```

</TabItem>
</Tabs>

By default, media starts at frame `0` and plays at its original speed and full volume.

## Adding background music

Add multiple media components to mix their audio together. This example plays a video with quieter, looping background music:

```tsx twoslash title="MyComposition.tsx"
import {Audio, Video} from '@remotion/media';
import {AbsoluteFill, staticFile} from 'remotion';

export const MyComposition = () => (
  <AbsoluteFill>
    <Video src={staticFile('video.mp4')} />
    <Audio src={staticFile('music.mp3')} volume={0.2} loop />
  </AbsoluteFill>
);
```

## Audio from video

A video's audio is included automatically. The same controls for volume, muting, speed and pitch apply to both `<Video>` and `<Audio>`.
To replace a video's sound with background music, add `muted` to `<Video>` in the example above.

## Trimming

Use `trimBefore` and `durationInFrames` to select a source range. See [Trimming, delaying and looping](/docs/audio/trimming#trimming).

## Delaying

Use `from` to start media later in the composition. See [Delaying](/docs/audio/trimming#delaying).

## Size and Position

Use CSS to [size and position a video](/docs/videos/size-and-position).

## Volume

Use `volume` to adjust levels and `muted` to silence media. See [Controlling volume and muting](/docs/audio/volume).

## Speed

Use `playbackRate` to speed up or slow down media. See [Controlling playback speed](/docs/audio/speed).

## Looping

Use `loop` to repeat media. See [Looping](/docs/audio/trimming#looping).
