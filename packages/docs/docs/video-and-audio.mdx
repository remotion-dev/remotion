Use [`<Video>`](/docs/media/video) and [`<Audio>`](/docs/media/audio) from [`@remotion/media`](/docs/media) to add media to your composition.
Both components support the same controls for timing, playback speed, volume and pitch.

Put `video.mp4` and `music.mp3` in your [`public` folder](/docs/terminology/public-dir) to play a video with background music:

```tsx twoslash title="MyComposition.tsx"
import {Audio, Video} from '@remotion/media';
import {AbsoluteFill, staticFile} from 'remotion';

export const MyComposition = () => (
  <AbsoluteFill>
    <Video src={staticFile('video.mp4')} />
    <Audio src={staticFile('music.mp3')} volume={0.2} loop />
  </AbsoluteFill>
);
```

The video's own audio is included. Add `muted` to `<Video>` to hear only the background music.
