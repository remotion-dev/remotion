SDK is a product by Remotion that is in development.

It aims to bring the capabilities of the Remotion framework, which allows people to dynamically create videos and motion graphics by writing React code and using agents, to developers wishing to integrate that functionality into their application.

## What is the difference between SDK and Editor Starter?

The [Editor Starter](/docs/editor-starter) operates on a JSON data payload that represents the state of the video. It is well suited for powering non-linear video editor applications whose data shape is well defined.

The SDK operates on React code and Remotion markup and features an in-browser compiler, allowing for more dynamically structured videos to be expressed, such as motion graphics.
