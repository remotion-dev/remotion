To export a Remotion composition as an OpenTimelineIO (`.otio`) timeline, use the [`remotion-render` Agent Skill](https://github.com/remotion-dev/remotion/blob/main/packages/skills/skills/remotion-render/SKILL.md). It preserves editable clips where possible and prerenders elements that cannot be represented in OpenTimelineIO.

[Install the Remotion Agent Skills](/docs/ai/skills), then ask your agent:
