# Exporting OpenTimelineIO<AvailableFrom v="4.0.544" />

Export a Remotion [composition](/docs/terminology/composition) as an OpenTimelineIO (`.otio`) timeline to continue editing in another video editor, such as DaVinci Resolve or Adobe Premiere Pro.

Exporting uses the [`remotion-render` Agent Skill](/docs/ai/skills#remotion-render). The agent inspects the composition, preserves editable clips where possible, and prerenders elements that OpenTimelineIO cannot represent.

## From Remotion Studio

<Step>1</Step> [Install the Remotion Agent Skills](/docs/ai/skills) in the project.

<Step>2</Step> Open a composition in [Remotion Studio](/docs/studio). Click the dropdown next to **Render**, then **Export as OpenTimeline...**.

## Using the skill directly

With the [Agent Skills installed](/docs/ai/skills), ask your agent:

<SuggestedPrompt prompt="/remotion-render Export MyComposition as an OpenTimelineIO (.otio) timeline for DaVinci Resolve." />

Include the composition ID and target editor. For a [parameterized composition](/docs/parameterized-rendering), also specify the input props to export.

## What gets exported

The export includes an `.otio` file and the media it references, placed together in an output folder. Keep them together when handing the edit to another person or moving it to another computer.

Media clips remain individually editable where possible. Text, animations, visual effects, and other elements that cannot be represented faithfully are rendered into media files. Audio processing may also be baked into separate clips or mixed stems.

The agent reports which elements remain editable and which have been prerendered. A prerendered element can be trimmed or moved in the destination editor, but its original React properties are not editable there.

## Open in a video editor

In DaVinci Resolve, choose **File → Import → Timeline...** and select the `.otio` file. In an editor with OpenTimelineIO support, use its timeline import action.

If media appears offline after moving the export folder, relink it to the media files in that folder. Check the imported picture and sound before continuing the edit.
