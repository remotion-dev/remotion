# @remotion/gsap<AvailableFrom v="4.0.517" />

import {TableOfContents} from './table-of-contents';

Use [GSAP](https://gsap.com/) timelines in Remotion.

GSAP normally advances animations on its own ticker, which runs on the wall clock. Remotion requires every frame to be a pure function of [`useCurrentFrame()`](/docs/use-current-frame). This package builds a paused GSAP timeline and seeks it to the current frame, so previews, scrubbing and renders are deterministic.

<Installation pkg="@remotion/gsap" />
