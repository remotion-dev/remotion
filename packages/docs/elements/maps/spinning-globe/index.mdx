# Spinning Globe

<ElementPage definition={getElementDefinition('maps/spinning-globe')} sourceFile="./spinning-globe.tsx" />

Requires WebGPU. Change the rotation speed, starting longitude, and shading in the Inspector. Negative speed reverses the rotation. Replace the texture with another equirectangular image to make a different globe.
