These 9:16 presets use official ad guidance for [TikTok In-Feed Ads](https://ads.tiktok.com/help/article/tiktok-auction-in-feed-ads), [Instagram Reels Ads](https://www.facebook.com/business/ads-guide/update/video/instagram-reels), and [YouTube vertical ads](https://support.google.com/google-ads/answer/9128498).

Live interfaces can vary by device, app version, locale, caption length, and placement. The interface shapes are illustrative; the safe-area geometry follows the linked guidance. The guide is visible in Remotion Studio and omitted from rendered output.
