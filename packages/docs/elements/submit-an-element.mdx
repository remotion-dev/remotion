# Submit an Element

Have a small, remixable Remotion Element? We'd like to see it.

Before starting, read the [Element Guidelines](/elements/guidelines). They describe the design and quality criteria for Elements.

## Use the Agent Skills

Three [Agent Skills](https://agentskills.io/) define the contribution workflow:

- Use the [`scaffold-element` Agent Skill](https://github.com/remotion-dev/remotion/blob/main/.agents/skills/scaffold-element/SKILL.md) to create the repository files and development composition.
- Use the [`submit-element` Agent Skill](https://github.com/remotion-dev/remotion/blob/main/.agents/skills/submit-element/SKILL.md) after reviewing the Element in Remotion Studio. It adds the Element to the gallery and generates the review assets for the pull request.
- Maintainers use the [`accept-element` Agent Skill](https://github.com/remotion-dev/remotion/blob/main/.agents/skills/accept-element/SKILL.md) to verify and upload the approved assets before merging.

Ask your coding agent to use the appropriate skill. Contributors do not need Remotion's upload credentials.

## Open the pull request

When submitting an Element as a pull request, include:

- The Element implementation, page, and gallery registration
- What makes it useful
- The rendered PNG and MP4 preview assets
- Links to inspiration, if any

The preview assets are temporarily committed so they work in the pull request deployment. A maintainer uploads them to `remotion.media` and removes them from the branch before squash merging. Keep “Allow edits from maintainers” enabled on the pull request; no force push is required.

[Open a pull request on GitHub](https://github.com/remotion-dev/remotion/compare)
