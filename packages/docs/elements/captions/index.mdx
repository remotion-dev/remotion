## How to use

### Transcribing in the Studio

<Step>1</Step> Select a video or audio.<br/>
<Step>2</Step> Click <kbd>Generate captions</kbd> in the inspector.<br/>
<Step>3</Step> In the <kbd>Styles</kbd> tab, keep Simple captions or choose a caption Element.<br/>
<Step>4</Step> For a selected Element, allow installing its code, then click <kbd>Generate captions</kbd>.<br/>

Style selection is available from <AvailableFrom v="4.0.534" inline />. Simple captions works without loading the Element library.

### Importing captions into Studio<AvailableFrom v="4.0.521" />

<Step>1</Step> Install an Element from below.<br/>
<Step>2</Step> Select its caption layer in Studio.<br/>
<Step>3</Step> In the Captions inspector, click <kbd>Import</kbd> and choose a file. <br/>

Supported formats:

- Remotion [`Caption[]`](/docs/captions/caption) JSON
- SRT
- ElevenLabs Speech-to-Text or segmented JSON
- OpenAI Whisper JSON transcript (verbose mode must be on)
