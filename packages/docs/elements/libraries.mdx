# Third-party Elements

Third-party libraries add more Elements to Remotion Studio. Each library's index is called an Element catalog.

After adding a library [programmatically](/docs/config#addelementlibrary) or, if available, through an [**Add to Studio** button](/docs/studio-protocol/add-element-library-to-studio) on its website, open the composition inspector and select **Browse Elements**.

Want to create a library? Read the [Studio Protocol integration guide](/docs/studio-protocol/component-library-integration).
